# 主进程文件清单（`electron/`）

按 `electron/` 根、`main.*.js`、`inno/` 与 `installer-assets/` 分组；目录树与整体机制见 [README.md](./README.md)。

## electron/（根）

| 文件 | 职责 | 关键导出 / IPC 通道 | 依赖与被依赖 |
| --- | --- | --- | --- |
| [`main.js`](../../../electron/main/main.js) | 主进程入口。解析命令行、启用 Node/渲染代码缓存、注册 `app://` 特权 scheme、单实例锁、`whenReady` 编排（建协议→建窗口→fork 后端）、主窗口/引导窗口/迁移与加密流程、`theme-chrome`/`quit-app`/原生右键菜单、数据目录搬迁与加密转换、退出收尾 | 无模块导出（被 Electron 入口加载）；`ipcMain.handle`：`open-external`、`get-master-key`、`get-pending-notification`、`get-setup-warmup`、`set-initial-data-dir`、`set-data-dir`、`set-db-encryption`、`set-thumbs-dir`；`ipcMain.on`：`quit-app`、`show-native-context-menu`、`theme-chrome`、`migration-ready`、`migration-dismiss`、`setup-ready`、`setup-complete`、`setup-quit` | 依赖全部 `main.*.js` 模块、electron、path/fs/crypto；被 `preload.js` 通过通道名间接对应 |
| [`preload.js`](../../../electron/preload.js) | 预加载脚本。用 `contextBridge` 暴露 `window.electron`（`send/on/off/once/invoke`）与 `window.__SECURE_CHANNEL__`，通过白名单约束收发通道 | `window.electron`、`window.__SECURE_CHANNEL__`；白名单：`validSendChannels`、`validInvokeChannels`、`validReceiveChannels` | 依赖 electron(contextBridge/ipcRenderer)；被各窗口 `webPreferences.preload` 引用 |
| [`startup.html`](../../../electron/startup.html) | 打包模式下引导窗口的静态占位页（纯内联 HTML/CSS，展示「班集 启动中…」，不依赖 JS，保证「秒出画面」） | 无 | 被 `main.js` 的 `createSetupWindow` 经 `app://local/setup.html` 使用（同源占位） |
| [`afterPack.js`](../../../electron/afterPack.js) | electron-builder `afterPack` 钩子（仅 win32）：剔除运行时用不到的 Chromium 组件、把 `LICENSES.chromium.html` 压缩为 `third-party-licenses.zip` | `module.exports = async function(context)` | 依赖 fs/path/zlib；被 electron-builder 打包流程调用 |
| [`app-icon.png`](../../../electron/app-icon.png) | 应用窗口/任务栏图标（`main.js` 的 `APP_ICON_PATH`），也被安装器自绘界面复用 | 无 | 被 `main.js`、`inno/setup.iss` 引用 |
| [`tray-icon.png`](../../../electron/tray-icon.png) | 系统托盘图标 | 无 | 被 `main.tray.js` 读取 |

| [`main.desktop-layer.js`](../../../electron/main/main.desktop-layer.js) | Windows「置底」定位（仅 Win32 生效）：**不做 `SetParent`**，用 koffi 的 `SetWindowPos` 把窗口插到「`Progman` 之上、所有可见窗口之下」（跳过 `Default IME`/`MSCTFIME UI` 这类不可见系统窗口），`isJustAboveDesktop()` 从 `Progman` 往上找自己来校验，`reassert()` 供点击/失焦/拖动结束后重新压回，`placeAboveDesktop()` 是原语 | 导出：`attach`、`detach`、`reassert`、`placeAboveDesktop`、`isJustAboveDesktop`、`getRect`、`moveWindow`、`isAvailable` | 依赖 koffi、user32；被 `main.widget.js` 引用（失败自动退回普通顶层窗口，总开关 `DESKTOP_LAYER_ENABLED`）。**不要再改回 `SetParent`**：子窗口被移动会让 Electron 原生崩溃（`0xC000041D`），详见 [widgets.md](../widgets.md) |
