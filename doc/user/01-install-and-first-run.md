# 01 · 安装与首次启动

## 前言

- **适用对象**：首次在电脑上安装班集的用户
- **本篇解决的问题**：完成安装、走完首次引导、选定安全等级并保存恢复词，直到进入主界面
- **前提条件**：Windows 10 1709 及以上；安装过程需要管理员权限（一次 UAC 确认）

---

## 具体方法

### 1. 安装

#### 1.1 系统版本要求

班集支持 Windows 10 1709 及以上版本。系统版本较低时，安装器和程序会先显示一屏提示，提供三个按钮：

- **退出程序**：停止安装；
- **忽略**：继续安装；同时勾选「不再提示」后，该提示不再出现；
- **获取最新的 Windows**：打开系统下载页，随后安装程序退出。

> **易错**：版本较低时选择「忽略」只表示不拦截安装，不代表运行稳定。安装后出现白屏或闪退时，升级系统比反复重装更有效。

#### 1.2 安装过程

1. 双击安装包。安装需要写入 `Program Files`，因此会触发一次 **UAC（用户账户控制）** 确认。
2. 安装界面为定制界面，共三项：
   - **安装路径**：默认 `C:\Program Files\班集`，可通过「浏览...」修改；
   - **用户协议**：点勾选框弹出协议全文，点「同意」后勾选生效；点「不同意」则保持未勾选，安装无法继续；
   - **桌面快捷方式**：默认勾选，可在「附加任务」中取消。
3. 点安装后，程序写入安装目录；结束时自动执行一次静默预热（不显示窗口），用于缩短首次启动时间。

> **建议**：安装路径保持默认更稳妥；安装到移动硬盘或 U 盘的版本，启动会变慢，部分场景下无法打开。

> **易错**：预热阶段安装器在等待后台进程退出。此时结束安装程序不影响功能，但会让首次启动明显变慢。

#### 1.3 启动与退出

启动入口为桌面快捷方式或开始菜单「班集」。

**单实例**：程序已运行时再次双击，不会打开第二个窗口，而是唤起已有窗口；主窗口此前关闭到托盘时，则重新创建主窗口。

关闭窗口不会直接退出，而是弹出「关闭班集」，由用户选择关闭范围：

| 选项 | 结果 |
| --- | --- |
| 关闭主窗口 | 只关主界面；浮窗工具箱、桌面小组件继续运行，程序留在托盘 |
| 关闭主窗口和工具箱 | 主界面与浮窗工具箱均关闭，桌面小组件继续运行 |
| 关闭主窗口和桌面组件 | 主界面与桌面小组件均关闭，工具箱继续运行 |
| 完全关闭 | 结束所有进程并停止后台服务，下次启动需要重新运行程序 |

中间两项在对应组件未开启时不可选。勾选「下次不再提示，直接按本次选择处理」后，之后点 × 会按上次选择执行。

从托盘恢复：左键单击托盘图标，或右键菜单「恢复主窗口」。彻底退出：托盘右键「完全退出」，或在关闭菜单选择「完全关闭」。

> **易错**：选择「关闭主窗口」后程序仍在托盘运行，计时器与后台服务继续工作；需要完全停止时应选择「完全关闭」。

### 2. 首次安装引导

首次启动不会直接进入主界面，而是打开「首次安装引导」窗口。欢迎页点「开始」后，先选引导方式：

| 方式 | 步数 | 内容 |
| --- | --- | --- |
| 快速引导 | 3 步 | 用户须知 → 账户设置 → 班级与学期 |
| 全面引导 | 6 步 | 用户须知 → 账户设置 → 班级与学期 → 主题选择 → 储存设置 → 功能开关 |

这一屏上「快速引导」默认选中，点另一张卡片可切换，底部「上一步」回欢迎页、「下一步」开始。

两种方式最终写入的设置完全相同。快速引导把主题、储存位置、三个功能开关都按默认值配好，不再单独列一屏摘要——既然选了「快速」，就不该再让用户逐个确认；要调整可在进入主界面后到「设置」里改。全面引导则是逐项确认。用户须知两种方式都要经过：许可与数据说明属于告知，不因选快速而省略。

左栏进度仅用于展示，不可点击跳转；前进与后退通过底部「上一步 / 下一步」。在第一步点「上一步」会回到「引导方式」选择屏。

| 步骤 | 内容 | 出现于 |
| --- | --- | --- |
| 用户须知 | 三条说明，点「下一步」继续 | 两者 |
| 账户设置 | 安全等级、用户名与密码；超级隐私另有恢复词子步骤 | 两者 |
| 班级与学期 | 班级名称（必填）、学期名称（必填）、学期起止日期（已按当前月份填好推荐值，可改） | 两者 |
| 主题选择 | 主题、日间/夜间、是否启用动画 | 完整 |
| 储存设置 | 数据目录（唯一根目录） | 完整 |
| 功能开关 | 工具箱、桌面小组件、插入新 U 盘自动打开（默认全不勾） | 完整 |

首次初始化（预热）的进度显示在窗口右上角的小毛玻璃胶囊里（「首次性能优化中 N%」，完成后变绿），整个引导过程都能看到，不占步骤、也不在最后一屏才出现。

> **易错**：在引导中点 × 会先弹出「温馨提示」确认（确认关闭引导吗，如果关闭引导，下次启动的时候需要重新引导），点「取消」可留在当前步骤，点「确认」才完全退出程序；退出后不记录「已完成引导」，下次启动仍从引导开始。**账号在点最后一步「完成」时才真正创建**，所以中途退出不会在库里留下任何账号，下次启动是一张干净的表单。

#### 2.1 用户须知（三条，两种方式都有）

许可与数据说明属于必须告知的提示，因此快速引导同样保留这一步，只是后面少了主题、储存、功能开关三项。完整条款见安装包内《用户协议》。

- **开源许可（MIT）**：软件按 MIT License 发布，可自由使用、复制、修改、分发，也可用于商业用途；分发时保留版权声明与许可声明即可。
- **本地优先，数据安全**：数据保存在本机，不采集、不上传；仅在 AI 助手、检查与下载更新时联网。
- **密码提醒**：设置密码并启用超级隐私模式后，密码与 12 词恢复词由用户自行保管；两者均丢失时无法恢复，开发者亦无法协助。

> **建议**：三条中第三条影响最大——安全等级与恢复词的选择决定后续能否找回数据，可在进入账户设置前先确定方案。

#### 2.2 账户设置

账户设置先选择安全等级（默认未选择，下拉显示「请选择模式」，必须自己选一次），再填写用户名（2–30 个字符）与密码（至少 6 位，需二次确认）。

| 界面上的名字 | 数据库加密 | 登录需要密码 | 恢复词 | 丢失后果 | 适用场景 |
| --- | --- | --- | --- | --- | --- |
| 明文模式（不加密） | 否 | 不允许设置密码 | 无 | 任何程序都能直接读取库文件 | 演示、数据不重要的场景 |
| 无密码模式（加密，免密码登录） | 是 | 否 | 无 | 数据加密，但能打开软件即可进入 | 担心遗忘密码、电脑仅单人使用 |
| 普通密码模式（加密 + 登录密码） | 是 | 是 | 无 | 换电脑后打不开；同一 Windows 用户仍可能被数据恢复工具打开 | 多数场景的默认选择 |
| 超级隐私模式（密码 + 恢复词才能解锁） | 是 | 是 | **12 词** | 密码与恢复词均丢失时永久无法打开 | 数据敏感、多人共用电脑 |

- 选择「普通密码模式」或「超级隐私模式」时会出现一次安全等级说明；超级隐私的说明框可点「取消」，退回普通密码模式。
- 仅超级隐私会在下一步多出「恢复密钥」子步骤：界面显示 12 个词，提供「下载文本」「复制」，并要求抄写前 3 个词、通过校验后才能完成注册。
- **账号在点最后一步的「完成」时才真正创建**。这一步通过后显示的是「账户信息已确认」，此时库里还没有账号；点「修改」可以返回改用户名或安全等级（恢复词会随之作废并重新生成）。中途关闭窗口也不会留下账号。
- 若点了「完成」时预热尚未跑完，会先弹一句「首次性能优化还未完成，进入程序可能会卡顿，请不用担心。」，点「知道了」照常进入。

> **易错**：恢复词仅在创建时显示一次。只截图存在相册、或只保存在同一台电脑上，恢复词会随设备一起丢失。

> **建议**：选择超级隐私后，手写或打印一份存放于固定位置，并在手机密码管理器另存一份；两处离线保存才算可靠。

> **建议**：记性一般且没有可靠保存习惯时，「无密码模式」比「普通密码模式」更不容易被锁在数据之外，数据同样加密。

#### 2.3 班级与学期

班级名称必填（如「高一（3）班」）。学期名称同样必填，进这一步时已按当前月份填好推荐值（例如 7 月及以后是「2026秋季学期」，1 月与 2–6 月各自有对应档位），起止日期也一并填好，确认或直接改都行。

学期起止日期不是装饰：课程表的「第几周」、值日与座位的快照补存范围、座位指数结算都按它计算。填反了（结束早于开始）会拦在这一步，不让继续。之后仍可在 `设置 → 学期设置` 调整。

> **说明**：班风与学风不在引导里问，进主界面后点首页班级信息框右上角的齿轮补填即可。

#### 2.4 主题选择（仅全面引导）

- 主题卡片点击即预览，默认毛玻璃主题。
- 部分主题没有夜间配色，此时日夜模式开关置灰并固定日间。
- 关闭「启用动画效果」会禁用全部过渡与动画（窗口淡入淡出、弹窗、列表动效），低配电脑可用它换取流畅度。

之后可在 `设置 → 主题设置` 再调整。

#### 2.5 储存设置（仅全面引导）

- **数据目录**：默认位于系统用户数据目录（`%APPDATA%\classnest\data`，点「打开」可直接查看）。这是全部本机数据的唯一根目录。
- 目录下固定分四层：`core`（数据库与密钥）、`content`（上传收据、相册索引、AI 技能、快照）、`cache`（相册缩略图等可再生缓存）、`logs`（运行日志）。四层不单独设置位置，随根目录一起搬迁。
- 修改目录会整体搬迁全部内容，后台服务会重启一次，向导会等待其就绪，界面短暂显示「处理中」。

> **易错**：数据目录位于网盘同步目录、临时清理目录或 U 盘时存在数据丢失风险。缩略图丢失可重新生成，数据库丢失只能依赖备份。

#### 2.6 功能开关（仅全面引导）

三项目前默认都不勾选：不勾选时进入主界面不会额外弹出任何窗口。快速引导不经过这一步，同样按「全不勾」处理，之后可在「设置 → 工具箱设置 / 桌面小组件设置」里改。

| 开关 | 勾选后的效果 | 默认 |
| --- | --- | --- |
| 启用工具箱 | 屏幕左边出现浮标，内含便签、截图与常用软件 | 不勾选 |
| 启用桌面小组件 | 桌面上出现置底显示的小组件（时钟、便签、常用软件），不挡操作 | 不勾选 |
| 插入新 U 盘时自动打开 | 插入新 U 盘时用文件资源管理器打开（仅 Windows） | 不勾选 |

- 三项都不是必选项，全部不勾也能正常使用。
- 进入该步骤时显示的是当前真实状态，并非每次都从空白开始。
- 之后可在 `设置 → 工具箱设置` 与 `设置 → 桌面小组件设置` 中随时修改；工具箱还可在浮标右键菜单里选「关闭工具箱」。

> **建议**：首次使用先保持默认，进主界面熟悉后再开工具箱；桌面小组件适合习惯看桌面时钟或便签的场景，不需要则不必开，可少一个常驻窗口。

#### 2.7 首次初始化（右上角进度）

引导窗口右上角（关闭按钮左侧）有一枚小毛玻璃胶囊，显示首次初始化的阶段与百分比（「首次性能优化中 N%」，完成后变为绿色的「首次性能优化已完成」）。它不占步骤，从进入引导起就一直在跑，不需要专门等待：点「完成」时会等待后台服务就绪（通常几秒），随后进入主界面。

若预热尚未跑完就点「完成」，会先弹出一句提示「首次性能优化还未完成，进入程序可能会卡顿，请不用担心。」，点「知道了」照常进入 —— 预热仍在后台继续，只是进入后的头几秒可能稍慢。该提示每次引导只出现一次。

### 3. 进入主界面后的 4 项设置

1. **核对账号**：`设置 → 账号管理`，确认用户名与安全等级符合预期（需要密码的档位也可在此修改密码；明文 / 无密码档没有这个按钮，改密码请走「安全等级」）。
2. **确认恢复词已有离线副本**（仅超级隐私）：除本机外，纸质与电子各一份更稳妥。
3. **做一次备份**：`设置 → 账号管理 → 导出数据库`。加密库需要设置导出密码；明文库导出的备份同为明文。换机时在**登录页 → 从备份恢复**，使用导出时的密码（或 12 词恢复词）解包。
4. **核对学期（推荐）**：引导第 3 步已填过学期，这里去 `设置 → 学期设置` 复核一眼开始与结束日期是否与本学期实际一致。课程表的「第几周」、座位与值日的快照补存范围、座位指数结算均按此计算。

### 4. 数据位置与卸载

- **数据位置**：默认 `%APPDATA%\classnest\data`（以「储存设置」中「打开」所见的路径为准），包含账号登记表、各账号加密库、主密钥文件、上传收据、缩略图、回收站、AI 记忆与技能等。
- **卸载程序**只移除安装目录中的程序文件，不改动数据目录。彻底删除数据需通过 `设置 → 危险操作 → 删除账号`（不可恢复，操作前建议先备份）。
- **更换电脑**有两种方式：
  - 常规方式：旧机「导出数据库」→ 新机完成安装 → 登录页「从备份恢复」；
  - 应急方式：完全退出程序后拷贝整个 `data` 目录（需包含 `db-master.key`）。

> **易错**：只拷贝 `<slug>.db` 而未拷贝 `db-master.key`（超级隐私还需密码或恢复词），加密库将无法打开。

### 5. 常见问题

**Q：双击图标后没有出现窗口？**
班集只运行一个实例：不会打开第二个窗口，而是唤起已有主窗口；主窗口此前关闭到托盘时，会重新创建主窗口。数秒后仍无窗口时，参考下一条。

**Q：安装时提示系统版本过低？**
见 1.1。低版本系统可以继续安装，但运行稳定性不保证，升级系统是更稳妥的选择。

**Q：首次启动很慢？**
安装结束时执行过一次预热；若该过程被打断，首次启动会补做初始化，进度走完后恢复正常。

**Q：白屏或长时间停在「加载中」？**
首次启动需要建库与预热，可先等待 1–2 分钟；仍无响应时完全退出后重新启动一次。反复出现时，附上 `data\backend.log` 与 `data\startup.log` 反馈，比重新安装更有效。

**Q：关闭引导后再次启动仍需重新填写？**
引导关闭时不记录「已完成」，已创建账户会保留，其余设置需要重新确认一遍。

**Q：忘记密码时如何恢复？**
- 超级隐私：登录页「忘记密码」→「使用恢复词恢复」，输入 12 个词与新密码；
- 普通密码：登录页「忘记密码」→「使用本机信息恢复」，同一 Windows 用户下可恢复，恢复后需设置新密码；
- 无密码 / 明文：同样走「忘记密码」→「使用本机信息恢复」，验证通过后直接进入系统（本来就没有登录密码，不需要再设一个）；

> **易错**：超级隐私账户没有本机恢复通道，仅恢复词一种方式。这是该等级换取严格保护的代价。

**Q：更换 Windows 账号或更换电脑后无法打开？**
主密钥由当前 Windows 用户的系统级加密（DPAPI）保护，更换 Windows 用户后不通用。迁移方式为「导出数据库」+「从备份恢复」，或整目录拷贝并在同一 Windows 用户下使用。
