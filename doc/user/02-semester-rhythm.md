# 02 · 一学期的使用节奏

## 前言

- **适用对象**：准备用一个学期完整跑通班集的用户
- **本篇解决的问题**：知道什么时候做什么，避免开学漏设、期末才发现数据没存
- **前提条件**：已完成安装与首次引导（见 [01 安装与首次启动](./01-install-and-first-run.md)）

---

## 具体方法

### 1. 开学前：把「底子」铺好

按顺序做，后面的页面都依赖前一步的数据：

| 顺序 | 做什么 | 入口 |
| --- | --- | --- |
| 1 | 建学期并填起止时间 | `设置 → 学期设置` |
| 2 | 导入或录入学生名单 | `学生管理 → 学生信息`（＋添加学生 / 从 Excel 表格批量导入） |
| 3 | 排座位、定座位模板 | `座位管理`（临时表排本周，模板表定长期） |
| 4 | 设课程表与节次 | `课程表`（先「设置」定节次，再排课） |
| 5 | 设值日项目与轮换 | `值日管理`（设置 → 智能排表 → 应用草稿） |
| 6 | 建分组（学习组、宿舍等） | `分组管理`（＋添加组 → 智能分组） |
| 7 | 登记班费期初与收据 | `班费管理` |
| 8 | 建相册并扫描照片 | `班级相册`（新建相册 → 选文件夹） |
| 9 | 录入班干部职务 | `学生管理 → 班干部管理` |

> **建议**：第 1、2 步完成后先执行一次「导出数据库」备份，后面所有数据都能回到这个起点。

### 2. 学期中：日常只碰三四个页面

- **每天**：首页看今日值日、请假、加分概况；需要时到对应页面录入。
- **每周**：座位、值日按周切换；周末看一眼 `座位管理 → 历史记录` 的周快照是否齐全。
- **每月**：班费对账、相册补齐、活动与倒计时更新。
- **随时**：AI 助手可用于查询统计、生成图表、批量整理；写入类操作会先出提案。

> **建议**：日常修改后不必刻意去存，表格与网格的改动会即时写入，并进入撤销记录（`Ctrl+Z` 可退）。

### 3. 期末：先导出，再动数据

| 顺序 | 做什么 | 入口 |
| --- | --- | --- |
| 1 | 导出备份 | `设置 → 账号管理 → 导出数据库` |
| 2 | 导出需要上报的表格 | 各页面「导出 Excel」 |
| 3 | 回看整学期快照与指数 | `座位管理 → 历史记录`、`值日管理 → 历史记录` |
| 4 | 相册索引导出留档 | `班级相册 → 导出相册索引` |
| 5 | 新建下一学期 | `设置 → 学期设置 → 增加学期` |

> **易错**：换学期前没备份。学期切换会影响座位快照与座位指数的结算范围（按当前学期起止日期计算），旧学期数据不会自动搬走，先导出再切更稳妥。
