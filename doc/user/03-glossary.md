# 03 · 名词表

- **适用对象**：遇到不熟悉的界面用语时查阅
- **本篇解决的问题**：用一个页面统一所有术语，后续篇目不再重复解释
- **前提条件**：无

---

术语按主题分组。后续篇目出现这些词时，均以本篇定义为准。

## 1. 时间与教学

| 术语 | 含义 |
| --- | --- |
| 学期 | 一段有起止日期的教学周期。`设置 → 学期设置` 可建多个学期，任一时刻只有一个「当前学期」。座位快照按天补存、座位指数结算都以当前学期的起止日期为范围 |
| 节次 | 课程表里「第 N 节」这一行。节数与每节课的时间在课程表「设置」里确定，之后排课按节次填 |
| 周 | 以周为单位的切换单元。座位、值日、课程表的「本周」都指当前自然周；历史记录可按周回看 |

## 2. 表格与网格

| 术语 | 含义 |
| --- | --- |
| 动态列 | 除核心字段外可自行增删改的列。学生名单与班费记录都支持；核心字段（如学号、姓名）受保护，不可删除 |
| 模板表 / 实行表 | 成对出现的两张表：模板表是长期使用的底稿，实行表（当前表）是本周实际使用的那份。座位、课程表、值日都有这一对 |
| 草稿 | 智能排表或智能分组先算出一份结果，尚未写入正式数据。草稿需点「确认应用草稿」才生效 |
| 快照 | 某一周（或某一天）数据的只读存档。历史记录里按周浏览，可补存已过日期、删除本周快照 |
| 补存 / 补录 | 手动把过去日期的数据补成快照，或在历史记录里补一条遗漏的记录 |
| 回填 | 用历史快照或模板把某周的数据恢复到正式表。座位、课程表、值日的历史区都提供回填入口 |

## 3. 座位与值日

| 术语 | 含义 |
| --- | --- |
| 座位模式 | 单桌（每列之间留走廊）或同桌（每两列为一组，组间留走廊）。`座位管理 → 设置` 里切换 |
| 显示走廊 | 网格中是否画出走廊列；只影响显示与编排，不影响名单 |
| 权重 | 给每个座位/劳动项目打的「辛苦程度」分。权重表与座位表同构，用来结算指数 |
| 座位指数 / 值日指数 | 按各自权重逐天累加出的公平账本，用来判断谁坐过/干过辛苦的位置 |

## 4. 分组与加分

| 术语 | 含义 |
| --- | --- |
| 维度 | 分组的一种视角，例如「学习小组」「宿舍」「值日组」。一个班级可同时有多个维度 |
| 小组 | 维度下的一个组，有自己的名称、成员与组长 |
| 命名规则 | 新增小组时的默认命名方式：自定义、第一组/第二组…、第 1 组/第 2 组…，以及带维度名前缀的两种变体 |
| 组长称谓 | 维度设置里的称呼，例如「学习组长」「宿舍长」 |
| 按加分 / 按扣分 / 净分 | 加分统计的三种口径：只算加分、只算扣分、加分减扣分 |
| 销假 | 学生返校后把请假记录标记为已结束。销假可撤销 |

## 5. 相册

| 术语 | 含义 |
| --- | --- |
| 索引 | 程序扫描文件夹后记下的照片条目（路径、拍摄时间、缩略图）。索引不等于文件本身 |
| 虚拟相册 | 由已有照片索引组合成的相册，只改索引归属，不移动磁盘上的文件 |
| 未知时间 | 图片里读不到拍摄时间的照片，统一归到时间轴最底部 |
| 全量更新 / 增量更新 | 全量重新扫描整个文件夹；增量只处理新增或变化的文件 |

## 6. 账号与安全

| 术语 | 含义 |
| --- | --- |
| 安全等级 | 明文模式、无密码模式、普通密码模式、超级隐私模式四档，决定库是否加密、登录是否需要密码、是否有恢复词 |
| 恢复词 | 超级隐私模式专属的 12 个词，是忘记密码时唯一的凭证，只在创建时显示一次 |
| 主密钥 | 解锁加密库的密钥。导出备份或整目录迁移时，缺少它会打不开库 |

## 7. AI 助手

| 术语 | 含义 |
| --- | --- |
| 提案 | AI 准备写入数据时先给出的一份改动清单，逐项列出将新增/修改/删除什么 |
| 全部审批 / 完全权限 | 两种写入权限：前者每次写入都要人工确认，后者由 AI 直接执行 |
| 数据改动 | AI 执行后生成的改动明细抽屉，可按表、按行查看并跳转到对应页面 |
| 技能 | 以 Markdown 文件保存的指令模板，在输入框打 `/` 调用 |
| 记忆文件 | 长期记忆，随对话自动注入；文件名称固定，不可删除 |

## 8. 撤销

| 术语 | 含义 |
| --- | --- |
| 撤销记录 | 每次编辑留下的可回溯条目，跨重启保留；在 `设置 → 撤销记录` 可查看、清空，或按条撤销 |
| 当前页 / 当前表 | `Ctrl+Z` 只作用于此刻所在页面的那张表，不会跨页面撤销 |
