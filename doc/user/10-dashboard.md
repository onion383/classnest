# 10 · 首页与今日

- **适用对象**：每天打开班集后先看总览的用户
- **本篇解决的问题**：看懂首页每张卡片代表什么、点进去到哪里、内容为空时该去哪补
- **前提条件**：已登录并至少有班级基础数据

---

## 1. 使用范围

首页是「只读总览 + 快捷入口」：每天到校看一眼今日值日、请假、加分与待办倒计时；要改内容时再进入对应页面。首页本身不承担录入。

## 2. 页面结构

### 2.1 班级信息框

顶部大框显示班级名称、班级口号、班风、学风，右侧有一个齿轮按钮（提示为「设置班名/口号/班风/学风」）。

- 点击齿轮打开编辑弹窗，四个字段都可修改，保存后立即生效。
- 框内的统计链接（学生数、请假、课程）可直接跳到对应页面。

### 2.2 卡片流

| 卡片 | 内容 | 点击后 |
| --- | --- | --- |
| 今日值日 | 今天轮到的小组/项目 | 值日管理 |
| 班费 | 收支概况，金额可一键显示/隐藏 | 班费管理 |
| 课程表 | 今天的课程 | 课程表 |
| 加分 | 今日加分概况 | 加分管理 |
| 活动 | 近期活动与倒计时 | 活动中心 |
| 请假 | 当前请假人数与名单 | 请假管理 |
| 相册 | 相册首图 | 班级相册 |

> **建议**：班费卡片上的「显示/隐藏金额」按钮只影响本次显示状态，适合在投屏或学生围观时使用。

## 3. 常见「空」状态

| 现象 | 原因 | 去哪补 |
| --- | --- | --- |
| 班级信息框只有名称 | 口号/班风/学风未填 | 点齿轮补填 |
| 今日值日卡片为空 | 值日表未排或本周无记录 | 值日管理 → 智能排表 / 直接编排 |
| 加分卡片为 0 | 今天还没有加分记录 | 加分管理 → 添加加分 |
| 课程卡片为空 | 课程表未设置节次或未排课 | 课程表 → 设置 / 编辑 |
| 相册卡片为占位图 | 相册没有照片或未索引 | 班级相册 → 新建相册 / 刷新 |
| 活动卡片为空 | 没有录入活动或倒计时 | 活动中心 |

## 4. 易错与建议

> **易错**：在首页看到的数据是缓存聚合结果，刚在别的页面改完，返回首页可能需要一瞬刷新；数字没变时可先等一次路由切换，避免误判为未保存。

> **建议**：首页卡片本身不提供编辑入口，改动一律到对应页面进行，避免同一份数据出现两个编辑口。
