# 11 · 学生名单

## 前言

- **适用对象**：需要录入、整理、导入导出学生数据的用户
- **本篇解决的问题**：会用动态列、行操作、导入导出与去重，把名单维护成唯一数据源
- **前提条件**：已登录；建议先在 `设置 → 学期设置` 建好当前学期

---

## 具体方法

### 1. 使用范围

开学导入名单、转学插班、调整列（如加「家长电话」）、批量清洗数据、交给学校上报时。

入口：`学生管理 → 学生信息`。

### 2. 界面结构

- 顶部工具栏：`＋ 添加学生`、`搜索`、`刷新`、`批量删除 (N)`、`从 Excel 表格批量导入`、`导出 Excel`、`去除重复数据`。
- 表格：首列勾选框 + `学号`、`姓名`（这两个是受保护字段，不可删除，表头带 `*` 标记）+ 自行添加的列 + 操作列（修改 / 删除）。
- 底部：`＋ 点击添加一行`，进入行内新增；已存在新增行时按钮变为 `取消添加一行`。
- 另一个标签页 `班干部管理`，见 [12 班干部](./12-cadres.md)。

### 3. 常用操作

#### 3.1 录入与编辑

1. `＋ 添加学生` 打开弹窗，按字段填写后保存。
2. 也可在表格底部点 `＋ 点击添加一行`，直接在行内填写，保存后落入正式数据。
3. 修改已有行：点操作列 `修改`，或直接编辑单元格（失焦保存）。
4. 点列名对该列进行关键字搜索；列名旁的放大镜 / 漏斗按钮打开筛选与排序面板（见 [33 表格通用交互](./33-tables.md)）。

#### 3.2 动态列

在表头或数据单元格上右键，可选：

- `修改列名`
- `在左侧插入列` / `在右侧插入列`
- `删除本列`（受保护字段显示为 `删除本列（受保护）` 并给出提示）

列可按住表头拖动换位置。

#### 3.3 行操作

在行上右键，可选：`上移`、`下移`、`在上面插入行`、`在下面插入行`、`剪切 (N)`、`🗑️ 删除 (N)`。

- 剪切后，在目标行右键会出现 `粘贴到上方 (N)` / `粘贴到下方 (N)`。
- 勾选多行后，工具栏的 `批量删除 (N)` 可一次删除选中行。
- 学生名单没有「至少保留一人」的限制，可以全部删空后再重新添加或导入。

#### 3.4 导入 Excel

路径：`从 Excel 表格批量导入` → 选择文件或把文件拖到弹窗 → 字段映射 → 预览 → `导入并合并保存`。

`＋ 添加学生` 弹窗的左上角也有 `从 Excel 表格批量导入` 按钮：点击后关闭单条录入弹窗，直接进入同一个批量导入弹窗；`修改学生` 时不显示该按钮。

- 只解析首个工作表；列会映射到现有字段，多余的列可选择忽略。
- 缺少受保护字段（学号/姓名）的行会被过滤，界面上会提示过滤了多少条。
- 文件体积上限 10MB，超过会被拒绝。

#### 3.5 导出

`导出 Excel` 打开导出面板：可选导出选中行或全部、勾选要导出的列、选择格式（网页、Excel、CSV、Markdown、纯文本、JSON、图片、PDF），再选择保存位置与文件名。格式差异见 [32 导入导出](./32-import-export.md)。

#### 3.6 去除重复数据

`去除重复数据` 打开去重弹窗，按提示选择判重依据并确认，处理结果以通知反馈。

### 4. 易错与建议

> **易错**：删除受保护字段或直接删库文件里的列，会导致导入、座位、加分等依赖姓名的功能找不到人。需要隐藏信息时另建列，`学号`、`姓名` 保持原样。

> **易错**：行内新增未保存就切页，新增行会丢失；离开前确认已保存或点 `取消添加一行`。

> **建议**：导入前先在 Excel 里把学号补全，避免整批被过滤；导入后跑一次 `去除重复数据`。

> **建议**：每次大批量导入或删列前，先 `设置 → 账号管理 → 导出数据库` 备份。
