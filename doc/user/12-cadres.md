# 12 · 班干部

## 前言

- **适用对象**：需要建立职务体系（班长、委员、组长等）的用户
- **本篇解决的问题**：会搭职务树、安排担任学生、调整层级，删除时知道会发生什么
- **前提条件**：学生名单已有数据

---

## 具体方法

### 1. 使用范围

开学定班委、中途换人、职务调整时。入口：`学生管理 → 班干部管理`。

### 2. 界面结构

- 顶部工具栏：`修改`（编辑当前选中的职务）、`＋ 添加职务`、`＋ 增加下级`、`刷新`、`导出 Excel`（导出去平后的职务名单）、`从 Excel 表格批量导入`。
- 主体是**职务树**：嵌套列表，每层是一个职务，职务下面是担任学生，可继续向下挂下级职务。
- 空态提示：点「＋ 添加职务」创建班主任、班长等职务，再逐级添加下级与担任学生。

### 3. 常用操作

### 3.1 建职务

1. `＋ 添加职务` 打开弹窗，填写两个字段：
   - **职务名称**：如「学习委员」「组长」；
   - **可担任人数**：该职务允许几人担任。
2. 选中某个职务后点 `＋ 增加下级`，会在它下面加一个下级职务（弹窗标题为「添加下级职务」）。
3. 编辑：先点选职务，再点 `修改`，弹窗标题变为「编辑职务」。

### 3.2 安排担任学生

- 在职务行内使用「添加学生」入口，选择学生后确认，提示「已添加担任学生」。
- 学生行可在职务内调整顺序。

### 3.3 调整层级与排序

- 按住职务拖动可改变排序与父子关系；拖到树的空白区域，该职务会变为顶级职务并排在末尾。
- 层级存在循环保护：不能把上级拖进自己的下级里。

### 3.4 删除职务

删除前会弹确认，提示内容取决于该职务是否有下级：

- 有下级：`确定删除职务「X」吗？其担任学生将一并删除，下级职务将上移到其上级。`
- 无下级：`确定删除职务「X」吗？其担任学生将一并删除。`

> **易错**：删除职务会连带删除其担任学生记录（不删除学生名单本身）。误删后可先到 `设置 → 撤销记录` 查看是否有对应条目并按条撤销；没有对应条目时只能按原职务重建。

### 3.5 导出名单

点 `导出 Excel` 打开导出弹窗。可选列：序号、职务、上级职务、层级、担任学生、已担任人数、可担任人数；职务按页面从上到下的顺序导出，同一职务的多名担任学生合并在「担任学生」一列。选择格式与文件名后导出。

### 3.6 从 Excel 表格批量导入

点 `从 Excel 表格批量导入` 可批量建立职务与担任学生，列与导出表一致；`添加职务` 弹窗左上角也有同一入口（编辑已有职务时不显示）：

- 必填 `职务`。
- `上级职务` 按**名称**匹配已有职务；留空表示顶级职务。上级必须已存在或在本文件更靠前的行里创建。
- `可担任人数` 仅在新建职务时生效；已存在的职务沿用原上限。
- `担任学生` 支持多人，用 `、` / `,` / `;` / 空格分隔；同名只有一位学生时会绑定到名单。
- `序号`、`层级`、`已担任人数` 是派生列，导入时忽略。

导入为合并追加：同一上级下的同名职务会复用，已有成员不会重复添加；超过 `可担任人数` 时整批导入被拒绝。

> **易错**：导出的文件可以原样导回（上级行排在前面）；如果手工调整了行顺序、把下级行放到上级行前面，会提示「上级职务不存在」，排序后重试即可。

格式与其它限制见 [32 导入导出](./32-import-export.md)。

### 4. 建议

> **建议**：先建主干（班长、副班长、学习/纪律/卫生委员），再逐级挂组长，避免一开始就建出很深的层级。

> **建议**：职务名称尽量固定写进班规，名称频繁变动会让「可担任人数」的统计口径反复调整。
