# 12 · 班干部

- **适用对象**：需要建立职务体系（班长、委员、组长等）的用户
- **本篇解决的问题**：会搭职务树、安排担任学生、调整层级，删除时知道会发生什么
- **前提条件**：学生名单已有数据

---

## 1. 使用范围

开学定班委、中途换人、职务调整时。入口：`学生管理 → 班干部管理`。

## 2. 界面结构

- 顶部工具栏：`设置`（编辑当前选中的职务）、`＋ 添加职务`、`＋ 增加下级`、`刷新`。
- 主体是**职务树**：嵌套列表，每层是一个职务，职务下面是担任学生，可继续向下挂下级职务。
- 空态提示：点「＋ 添加职务」创建班主任、班长等职务，再逐级添加下级与担任学生。

## 3. 常用操作

### 3.1 建职务

1. `＋ 添加职务` 打开弹窗，填写两个字段：
   - **职务名称**：如「学习委员」「组长」；
   - **可担任人数**：该职务允许几人担任。
2. 选中某个职务后点 `＋ 增加下级`，会在它下面加一个下级职务（弹窗标题为「添加下级职务」）。
3. 编辑：先点选职务，再点 `设置`，弹窗标题变为「编辑职务」。

### 3.2 安排担任学生

- 在职务行内使用「添加学生」入口，选择学生后确认，提示「已添加担任学生」。
- 学生行可在职务内调整顺序。

### 3.3 调整层级与排序

- 按住职务拖动可改变排序与父子关系；拖到树的空白区域，该职务会变为顶级职务并排在末尾。
- 层级存在循环保护：不能把上级拖进自己的下级里。

### 3.4 删除职务

删除前会弹确认，提示内容取决于该职务是否有下级：

- 有下级：`确定删除职务「X」吗？其担任学生将一并删除，下级职务将上移到其上级。`
- 无下级：`确定删除职务「X」吗？其担任学生将一并删除。`

> **易错**：删除职务会连带删除其担任学生记录（不删除学生名单本身）。误删后可先到 `设置 → 撤销记录` 查看是否有对应条目并按条撤销；没有对应条目时只能按原职务重建。

## 4. 建议

> **建议**：先建主干（班长、副班长、学习/纪律/卫生委员），再逐级挂组长，避免一开始就建出很深的层级。

> **建议**：职务名称尽量固定写进班规，名称频繁变动会让「可担任人数」的统计口径反复调整。
