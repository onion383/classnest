# 13 · 座位表

## 前言

- **适用对象**：需要排座位、轮换座位、回看历史座位的用户
- **本篇解决的问题**：分清临时表与模板表，会用智能排表、权重表、快照与回填
- **前提条件**：学生名单已有数据；建议已设当前学期（影响快照与指数结算）

---

## 具体方法

### 1. 使用范围

开学排座位、每次考试重排、按周轮换、查看某周谁坐哪里、结算座位公平性时。

入口：`座位管理`。

### 2. 界面结构

页面顶部有两个标签页：

| 标签页 | 内容 |
| --- | --- |
| 座位管理 | 座位表（临时表 / 模板表）、座位位置权重表 |
| 历史记录 | 座位指数、座位记录（周快照）、补录、删除快照 |

### 3. 座位表（临时表与模板表）

#### 3.1 两张表的区别

- **临时表**：当前实际使用的座位，日常改动都在这里。
- **模板表**：长期底稿，用来在排新一周或新学期时一键套用。

两张表通过标题右侧的视图切换切换；除导入按钮文案不同外，操作方式一致。

#### 3.2 工具栏

`设置`、`智能排表`、`刷新`、`从模板导入`（临时表）/`从实行导入`（模板表）、`导出 Excel`。

#### 3.3 排座位

1. 打开 `设置`，填写：
   - **行数**、**列数**；
   - **座位模式**：单桌（每列间有走廊）或同桌（每两列为一组，组间有走廊）；
   - **显示走廊**：是否在网格里画走廊列。
2. 缩小范围且外部仍有座位数据时，界面会说明座位范围小于外部已有数据，并询问是否舍弃外部数据。
3. 双击格子输入姓名（候选列表按姓名匹配，已在其他格出现的学生不会重复出现）。
4. 按住行首或列头拖动，可整行/整列交换位置。
5. 排完后点 `导出 Excel` 可留存或张贴。

#### 3.4 智能排表

`智能排表` 先算出方案并生成**草稿**，界面会弹「确认应用草稿」；确认后才写入座位表。草稿可反复生成，不确认则不影响现有座位。

#### 3.5 座位位置权重表

与座位表同构，格内填数字表示该位置的「辛苦程度」。

- 工具栏：`设置`（权重算法）、`刷新`、`导出 Excel`。
- 权重用于结算座位指数：按每人所坐位置的权重逐天累加。

> **建议**：权重表不必每周改，它表达的是一段时间内的公平规则；频繁改动会让指数失去可比性。

### 4. 历史记录

#### 4.1 座位指数

- 多人横向长条，按所坐位置权重逐天累加，截至所选周。
- 没有快照时显示：`暂未有历史快照，无法结算座位指数`。
- 工具栏：`刷新`、`导出 Excel`。

#### 4.2 座位记录（周快照）

- 顶部周切换条可切到任意周，下方显示该周快照，底部标注「代表日期」。
- 操作按钮：
  - `补存已过日期`：把已过去、但还没存成快照的日期补存；
  - `删除本周快照`：删除当前周的记录，需二次确认（标题「删除历史快照」）。
- `设置` 里可选择学期，并管理周记录。
- `补录记录` 用于手工补一条遗漏的座位记录。
- `导出 Excel` 导出当前周的座位记录。

### 5. 易错与建议

> **易错**：把「模板表」当成日常座位改。模板表是底稿，改它不会立刻更换本周座位；要影响本周，应改临时表，或用「从模板导入」。

> **易错**：以为智能排表点一下就生效。未点「确认应用草稿」时，座位没有任何变化。

> **易错**：删除了本周快照后无法撤销座位指数历史，只能重新补存；删除前建议先 `导出 Excel`。

> **建议**：每周固定一天检查历史记录是否齐全，缺的用「补存已过日期」补上，指数才连续。
