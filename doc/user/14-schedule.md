# 14 · 课程表

- **适用对象**：需要排课、轮换课表、回看某周上过什么课的用户
- **本篇解决的问题**：先定义作息时间，再分清实行课表与一般课表，会用周快照
- **前提条件**：已登录；已在 `设置 → 学期设置` 建好当前学期（学期开始日期用于周次与快照归属）

---

## 1. 使用范围

开学排课、临时调课、查看某周的实际课表、把一套课表留成底稿、导出张贴时。

入口：`课程表`。

## 2. 界面结构

页面顶部有两个标签页：

| 标签页 | 内容 |
| --- | --- |
| 课程表管理 | 实行课表、一般课表、导出 |
| 历史课程表记录 | 按周查看已保存的课表快照 |

`课程表管理` 内部通过视图切换在 `实行课表` 与 `一般课表` 之间切换。

- **实行课表**：本周实际执行的课表，日常调课改这里。
- **一般课表**：长期底稿，用来在新的一周或新学期一键套用。

两张表的工具栏都是 `设置`、`刷新`、`导出 Excel`，导入按钮文案不同：

- 实行课表：`从模板导入`（把一般课表复制过来）；
- 一般课表：`从实行导入`（把当前实行课表存成底稿）。

## 3. 第一次配置：作息时间设置

在任一视图点 `设置`，打开 `⏱️ 作息时间设置`：

1. **学期开始日期**：决定周次起点，也是历史快照按周归属的依据。
2. **一周天数**：从上到下的第一个星期几，到选定的最后一个星期几；表格列随之变化。
3. **五个时段**：上午、中午、下午、傍晚、晚上。每个时段可 `＋ 新加…时间段`。
4. 每条时间段包含：
   - **类型**：`学习` 或 `休息`；
   - **名称**（如 `第一节`、`大课间`、`午休`）；
   - **起止时间**；
   - 删除按钮。
5. 保存设置后，表格按「学习」条目的顺序重建可填写的行。

类型为 `休息` 的条目在表格中是一条整行只读的休息条，显示名称与时间，不填科目；类型为 `学习` 的条目才生成可填科目的格子。

> **建议**：作息时间在学期初一次定好。学期中增减节次会让新旧课表的行对不上，历史对比容易看错。

## 4. 排课

1. 表格首行是 `讲  台`，只读；下方每行是作息设置里的学习时段，每列是一个星期几。
2. 双击格子输入科目；也可用候选列表选择，科目候选包括 `语文`、`数学`、`英语`、`物理`、`化学`、`生物`、`历史`、`政治`、`地理`、`体育`、`信息`、`音乐`、`美术`、`班会` 等。
3. 列与行支持拖动、右键菜单，与其它表格一致，见 [33 表格通用交互](./33-tables.md)。
4. 每格修改即时写入，并进入撤销记录，`Ctrl+Z` 可退。

### 4.1 在两张表之间套用

- 实行课表 → `从模板导入`：选择 `一般课表` 的内容覆盖当前实行课表，界面会先确认。
- 一般课表 → `从实行导入`：把当前实行课表存为底稿，界面会先确认。

导入是对整张表的覆盖，不是合并。

## 5. 历史课程表记录

- 顶部周切换条可切到任意周；没有快照时显示空状态。
- `📸 保存本周快照`：把当前实行课表存成「本周」的快照。
- `🗑 删除本周快照`：删除当前显示周的快照，确认弹窗会带上该周日期范围，并说明删除后不可恢复。
- `导出 Excel` 导出当前显示的课表。

> **易错**：快照保存的是**保存那一刻**的实行课表。调课之后不重新保存，历史里仍是旧版本。

> **易错**：删除本周快照不可恢复，也没有撤销入口；删除前建议先 `导出 Excel` 留一份。

> **建议**：固定每周同一天保存一次快照（例如周五放学前），期末回看时每周都有记录。

## 6. 易错与建议

> **易错**：把「一般课表」当成本周课表改。一般课表是底稿，改它不会立刻影响本周；要影响本周，应改实行课表，或用「从模板导入」。

> **易错**：从模板导入是整表覆盖。已有临时调课未保存快照时，覆盖后原内容只能靠撤销或重新排。

> **建议**：开学第一周把一般课表排好，之后每周只在实行课表上做局部调整。
