# 16 · 分组管理

## 前言

- **适用对象**：需要建学习小组、宿舍组、值日组等固定分组的用户
- **本篇解决的问题**：会建分组维度、维护小组与成员，会用智能分组并安全地替换现有安排
- **前提条件**：学生名单已有数据

---

## 具体方法

### 1. 使用范围

开学分学习小组、分宿舍、按组评比与加分、按组排值日之前。

入口：`分组管理`。

### 2. 界面结构

- 顶部：维度标签页（一个标签是一套分组，如「学习小组」「宿舍管理」）、`+ 添加组`。
- 工具条：`设置`、`🧠 智能分组`、`刷新`、`从 Excel 表格批量导入`（有当前维度时显示）、`导出分组`。
- 主体：当前维度下的小组卡片网格；每个普通维度末尾有 `＋ 添加小组` 虚线卡片。
- 内置的宿舍维度为左右两栏（男生宿舍 / 女生宿舍），没有「添加小组」卡片。
- 首次创建时男/女生宿舍数默认为 0，需要到「设置」里填写后才生成宿舍组。

### 3. 建一个分组维度

`+ 添加组` 打开弹窗：

| 字段 | 说明 |
| --- | --- |
| 组名 | 如 `学习小组`、`宿舍管理` |
| 组名排序 | `自定义`、`第一组，第二组…`、`第1组，第2组…`、`{组名} 第一组…`、`{组名} 第1组…` |
| 每组人数 | 智能分组时按此人数切分 |
| 组数 | 初始化的小组数量，之后可增减 |
| 组长称呼 | 如 `宿舍长` / `学习组长` |

选择非「自定义」的组名排序时，初始化小组会按该规则自动生成组名。

### 4. 维护小组与成员

- 小组卡片右上角 `＋` 添加成员，`✕` 删除整个小组。
- 成员表三列：序号、成员、备注。
  - 第一行显示为组长称呼（如 `舍长`），其余为 1、2、3…；
  - 成员姓名与备注为行内编辑，失焦或回车保存；
  - 左侧 `⠿` 可拖动调整成员顺序，第一行即组长；
  - 行尾 `✕` 移除该成员。
- 卡片底部 `＋ 添加小组` 新增空小组。

#### 4.1 分组设置

`设置` 只对当前维度生效，字段与「添加组」相同，另有 `删除当前分组`：

- 修改 `组数` 会按需自动补充或删除小组；
- 选择组名排序规则并保存后，现有小组会按规则重命名；
- 内置宿舍维度按 `男生宿舍数`、`女生宿舍数` 分组，组名不可修改，也不可删除。

> **易错**：改 `组数` 减少时被删掉的小组，其成员与备注一并消失。减少前建议先 `导出分组` 留档，或把成员移到保留的小组。

### 5. 智能分组

点 `🧠 智能分组`：

1. **分组条件**从下方拖入上方，可拖动 `⠿` 调整顺序。
2. 可用的条件类型：
   - **特殊关系**：`在一组` / `不在一组`，选择两名学生；
   - **指定身份**：`担任组长` / `不担任组长`，选择学生；
   - **性别比例**：`男女尽量均匀` / `全为男生或女生（每组同一性别）`。
3. 条件按顺序依次生效，**越靠后的条件越重要**，可部分覆盖前面的结果；每条右侧显示 `满足 N%`。
4. `▶ 开始排表` 生成预览，`🔀 换一换` 重新生成；下方预览每个小组与组长。
5. `确定` 后写入当前维度的各小组，界面提示「智能分组已应用」。

- 若小组里存在学生信息表中找不到的名字，弹窗会先提示「新同学」确认。
- 结果只预览，不点 `确定` 不会改动现有分组。

> **易错**：智能分组会按预览结果整体重建当前维度的小组与成员，手工调整过的成员顺序和备注要被替换。分组前先 `导出分组` 更稳妥。

### 6. 撤销与导出

- 增删小组、增删成员、成员拖动排序、智能分组应用，都会记为「分组结构变更」，可在 `设置 → 撤销记录` 查看并按条撤销。
- `Ctrl+Z` 在分组页同样可用，撤销的是最近一次结构变更。
- `导出分组` 打开导出面板，选择要导出的小组与格式。

### 7. 从 Excel 表格批量导入

工具条的 `从 Excel 表格批量导入` 会把成员写进**当前维度**；`添加小组` 弹窗左上角也有同一入口：

- 必填 `小组`、`姓名`；可选 `备注`。
- 同名小组存在则复用；普通维度下不存在的组名会自动新建小组。
- 同一小组内重复的姓名会跳过并提示跳过数量，不会重复写入。
- 内置宿舍维度不能新建小组：组名必须是「设置」里生成过的宿舍名，否则导入被拒绝。
- 每组人数受维度「每组人数」限制，超出时整批导入不写入。

导入会记入「分组结构变更」，可用 `Ctrl+Z` 撤销。

格式与其它限制见 [32 导入导出](./32-import-export.md)。

> **建议**：日常零散调整用行内编辑（可单条撤销）；整班重排用智能分组，先在预览里核对组长与人数。
