# 17 · 加分管理

- **适用对象**：需要给个人或小组做日常加减分、按周或期末统计的用户
- **本篇解决的问题**：会用两种加分对象、三种统计口径，会看今日时间轴与加分统计
- **前提条件**：学生名单已有数据；小组加分需要先在 `分组管理` 建好分组维度与小组

---

## 1. 使用范围

课堂表现、卫生纪律、活动评比后即时记录；班会公布当日加减分；期末汇总评比时。

入口：`加分管理`。

## 2. 界面结构

- **加分对象**（右上角下拉）：`个人加分`、`小组加分`。两者数据完全独立，各自有记录与统计。
- **标签页**：`今日加分`、`加分统计`。
- **工具栏**：`＋ 添加个人加分` / `＋ 添加小组加分`、`刷新`、`📥 导出个人加分` / `📥 导出小组加分`。
- **统计口径**（加分统计页右上角）：`按加分`、`按扣分`、`净分（加-扣）`。

## 3. 添加一条记录

弹窗字段：

| 字段 | 说明 |
| --- | --- |
| 学生姓名 / 学号 / 小组 / 成员数 | 选择后自动带出的只读信息 |
| 选择学生 | 个人加分时必填，可输入姓名搜索 |
| 选择小组 | 小组加分时必填；先选分组维度，再选小组 |
| 类型 | `＋ 加分` / `－ 扣分` |
| 项目 | 如 `卫生` / `纪律` / `学习` / `助人`，有快捷项目可选 |
| 分值 | 数值 |
| 加分时间 | 默认当前时间，可改 |
| 原因 | 展示在时间轴与导出里的说明 |

- 小组加分会给组内每位成员各记一条，保存前弹窗会列出将要记录的成员与人数。
- 保存后提示成功，记录立即出现在今日时间轴与统计中。
- 编辑既有记录用弹窗内的 `删除` 或行内 `编辑`；确认弹窗后才真正删除。

## 4. 今日加分

- 时间轴按时间排列当天记录，节点文案为「某某 因为 原因 加/扣 N 分」；小组记录显示小组名。
- 每个节点可 `编辑` / `删除`。
- 无数据时显示 `今天还没有人加分` / `今天还没有小组加分`，并给出 `去加分` 入口。
- 跨过零点后，今日视图会自动换成新一天的记录。

## 5. 加分统计

- 以横向长条展示当前口径下的分值，按分值排序；小组加分按小组汇总。
- `按加分` 只累计加分，`按扣分` 只累计扣分，`净分` 为加分减扣分（负值时以警示色显示）。
- `刷新` 重新取数；`导出` 导出当前口径的两列表（姓名/小组 + 加分/扣分/净分）。

## 6. 导出

`📥 导出个人加分` / `📥 导出小组加分` 打开导出面板：

- 在 `今日加分` 页导出当天记录，列为：个人（姓名、学号）或小组（小组、成员数），加类型、项目、分值、加分时间、原因。
- 在 `加分统计` 页导出当前统计口径的汇总。
- 支持网页、Excel、CSV、Markdown、纯文本、JSON、图片、PDF 等格式，见 [32 导入导出](./32-import-export.md)。

## 7. 易错与建议

> **易错**：小组加分按「当时的成员」逐人写记录。事后再调整小组成员，已记录的分数不会自动跟着变，需要编辑或重新添加。

> **易错**：`按扣分` 口径不会显示加分，`净分` 才同时体现加减；公布分数前先确认右上角的口径。

> **建议**：项目名保持稳定（如统一用 `卫生`、`纪律`），期末统计与纵向对比才清晰。

> **建议**：一次性给整组加分时，先在弹窗里核对成员名单，确认没有漏人或已转出的学生。
