# 18 · 请假

## 前言

- **适用对象**：需要登记学生请假、跟踪返校、查看今日到班情况的用户
- **本篇解决的问题**：会登记与销假、会用今日看板与逾期提醒，避免在校人数长期不准
- **前提条件**：学生名单已有数据；建议在名单里补好家长联系电话

---

## 具体方法

### 1. 使用范围

学生当天请假、连续请假、返校销假、早上核对到班人数、期末统计请假次数时。

入口：`请假管理`。

### 2. 界面结构

- **顶部看板**：`全班人数`、`在校人数`、`当前请假`。
- **标签页**：`今日到班`、`请假记录`。
- **视图**：`表格`、`时间轴`。
- **工具栏**：`＋ 添加请假`、`刷新`、`从 Excel 表格批量导入`（请假记录页）、`导出今日表`（今日到班页）/ `导出请假记录`（请假记录页）。

`今日到班` 页还包含：`请假统计`（按学生汇总病假、事假、其他与合计）、`请假记录` 明细。

### 3. 登记请假

`＋ 添加请假记录` 打开 `请假登记` 弹窗：

1. **选择学生**（必填，可输入姓名搜索）。
2. **家长联系电话**、**学生联系电话**：从名单带入，可双击编辑。保存请假时若联系方式有改动，会询问是否同步到班级管理的学生档案；选择同步后写回名单。
3. **请假类型**（必填）：`病假`、`事假`、`其他`。
4. **请假时段**（必填）：快捷按钮 `今日全天`、`今日上午`、`今日下午`、`今日晚修`、`今日不过夜`、`明天全天`、`连续两天`、`连续三天`，默认 `今日全天`；也可手动调整。
5. **开始时间**、**结束时间**：决定这条请假何时算「已结束」。
6. **备注**。
7. `确认请假` 后写入记录。

### 4. 销假与撤销销假

- `今日到班` 页分两组：`当前请假中（N人）` 与 `今日已返校（N人）`。
- 当前请假中的行有 `编辑`、`销假`；已返校的行有 `编辑`、`撤销销假`。
- 其他单元格可双击就地编辑（如类型、电话），失焦保存。

> **易错**：学生已返校但不点 `销假`，`当前请假` 与 `在校人数` 会一直不对；每天到校后先处理一次已返校名单。

### 5. 逾期提醒

有请假已过结束时间但仍未销假时，进入页面会弹出 `⏰ 发现假期已结束`：

- 列出姓名与请假时段；
- `未返校`：保持请假状态，继续计入当前请假；
- `已经返校并销假`：立即完成销假。

> **建议**：同一条记录在同一次使用会话内只提醒一次，重启班集后仍会再次出现；处理完再离开，避免旧记录越积越多。

### 6. 从 Excel 表格批量导入

`请假记录` 页的工具栏有 `从 Excel 表格批量导入`，用于批量补录历史请假；`请假登记` 弹窗左上角也有同一入口（编辑已有记录时不显示）。

- 必填列：`姓名`、`开始时间`、`结束时间`。缺少这三列的行会被过滤并提示条数。
- 可选列：`学号`、`类型`（默认 `其他`）、`家长联系电话`、`学生联系电话`、`状态`（默认 `请假中`）、`返校时间`、`备注`。
- 填了 `学号` 会按学号精确匹配学生；只填姓名时，同名只有一位学生才会匹配。
- 匹配到学生后，联系电话未填写会自动带出名单里的号码。
- 结束时间早于开始时间的行会被拒绝，整批导入不写入。
- 导入为追加合并，不会覆盖已有记录。

格式与其它限制见 [32 导入导出](./32-import-export.md)。

### 7. 导出与统计

- `导出今日表`：导出今日到班情况（含当前请假与已返校名单）。
- `请假统计` 的 `导出`：按学生汇总 `病假`、`事假`、`其他`、`合计`，合计降序、同数按姓名排序。
- `请假记录` 页的 `导出请假记录`：导出全部明细。

格式选择见 [32 导入导出](./32-import-export.md)。

### 8. 易错与建议

> **易错**：请假类型与时段是统计口径的来源，事后补登时按实际时间填写，统一选「今日全天」会让统计与导出失真。

> **易错**：`编辑` 改结束时间不会自动销假；改完仍需要在已返校时点 `销假`。

> **建议**：把「早上看今日到班、放学前处理逾期」固定成日常动作，看板数字才可信。
