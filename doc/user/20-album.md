# 20 · 相册

## 前言

- **适用对象**：需要把班级照片集中浏览、按时间回看、挑选照片建相册的用户
- **本篇解决的问题**：会建相册与扫描、会用时间轴与虚拟相册、会处理扫描任务与删除
- **前提条件**：照片已在电脑的某个文件夹里；建议把照片放在一个固定目录

---

## 具体方法

### 1. 使用范围

活动后整理照片、按月份回看、给某次活动挑一组精选、把多个相册合成一个时。

入口：`班级相册`。

### 2. 界面结构

- **顶部标题栏**：`照片`（已索引照片总数，按文件去重）、`相册`、总占用体积。
- **工具栏**：`新建相册`、`管理相册`、`任务管理`、`多选`、`导出相册索引`、`刷新`。
- **视图切换**：`时间轴`、`相册`。

扫描进行时，标题栏下方会提示「正在更新照片索引…」，可到 `任务管理` 查看进度或停止。

### 3. 新建相册

`新建相册` 弹窗有两种来源：

| 来源 | 说明 |
| --- | --- |
| 文件夹 | 选择电脑上的文件夹，递归读取其子文件夹里的照片与视频；相册名称默认取文件夹名，可改 |
| 其他相册 | 从已有相册里挑选照片，组成一个不绑定文件夹的相册（虚拟相册） |

- 文件夹相册只建立索引，不移动、不修改磁盘上的文件。
- 虚拟相册只保存索引，照片文件仍在原相册对应的文件夹里。

### 4. 时间轴视图

- 照片按拍摄日期分组，日期从 EXIF 读取；读不到拍摄时间的照片归到最底部的 `未知时间` 分组。
- 分组标题旁会提示该组里有几张读不到时间。
- 点击照片进入查看器：可 `▶` 播放（视频）、`信息`（查看基础信息与照片信息）、`另存`、`打开文件夹`、`删除（回收站）`；支持滚轮缩放与播放倍速。
- 相册多于一个时，时间轴上方有相册切换条，括号内是该相册的照片数。

### 5. 相册视图与多选

- 相册视图以卡片列出所有相册，虚拟相册带 `虚拟` 标记。
- 点 `多选` 进入选择态：
  - 在**时间轴**里选照片，可移动到其它相册；
  - 在**相册视图**里选虚拟相册，可 `合并相册（N）`。
- 合并只合并索引，生成一个新的虚拟相册，**不移动磁盘文件**；参与合并的源虚拟相册会被移除。
- 文件夹相册不能参与合并，选择时会提示。

> **易错**：合并会移除源虚拟相册。合并前确认选中的都是需要保留内容的虚拟相册。

### 6. 任务管理

`任务管理` 弹窗列出所有相册的扫描进度：

- 顶部汇总行：`更新所有相册照片`，有总进度，按钮为 `继续` / `暂停`、`停止`、`增量更新`、`全量更新`。
- 每个相册一行：状态（`排队中`、`已暂停`、`增量更新` / `全量更新`）、进度、`暂停` / `继续`、`停止`、`增量更新`、`全量更新`。
- 任务一次只跑一个相册；`更新所有相册照片` 会把各相册依次排队。
- 暂停后进度不丢，`继续` 从检查点接着跑。
- 软件自动发起的扫描（新建相册、撤销/重做）也会显示在对应行。
- 虚拟相册没有文件夹，不参与扫描。

增量更新只处理新增或变化的文件；全量更新会重新遍历整个文件夹，耗时更长。

### 7. 管理相册、删除与撤销

- `管理相册`：查看相册列表、拖 `⠿` 排序、在文件管理器中 `打开文件夹`、删除相册。
  - 删除确认会说明「仅删除索引，不删除磁盘照片」；删除后照片文件仍在原文件夹。
  - 虚拟相册显示索引来自其他相册，没有「打开文件夹」。
- 查看器里的 `删除（回收站）` 会把照片移入系统回收站；该操作进入撤销记录，`Ctrl+Z` 可还原。
- 添加相册、删除相册、相册排序、删除照片都支持撤销与重做，见 [30 撤销与重做](./30-undo.md)。

> **易错**：以为删除相册就删掉了照片。删除相册只删索引；反过来，想彻底清理照片需要到系统回收站或原文件夹处理。

> **易错**：把照片文件夹移走后，相册里的状态会失效；重新扫描前先确认文件夹路径仍然有效。

### 8. 导出相册索引

`导出相册索引` 导出照片清单（文件名、路径、拍摄时间、所属相册等），用于留档或核对缺失照片。图片类格式在该入口被屏蔽，避免导出成一张张图片。

> **建议**：每学期末导出一次相册索引，配合 `设置 → 账号管理 → 导出数据库` 一起留档，换机后可对照补齐。
