# 21 · 活动

## 前言

- **适用对象**：需要记录班级活动、设置重要日期倒计时的用户
- **本篇解决的问题**：会新增与回看活动、会设置与维护倒计时
- **前提条件**：已登录；活动照片另行建在 `班级相册`

---

## 具体方法

### 1. 使用范围

主题班会、运动会、文艺晚会、社会实践之后补记；考试、放假、毕业等重要日期需要提醒时。

入口：`班级活动`。

### 2. 界面结构

页面顶部有两个标签页：`日常活动`、`倒计时`。

#### 2.1 日常活动

- 工具栏：`＋ 新增活动`、`刷新`、`从 Excel 表格批量导入`、`📥 导出活动`。
- 主体是活动时间轴，按时间排列，节点显示主题、地点、参与人员与状态标签：
  - `未开始`（活动日期在今天之后）；
  - `进行中`（活动日期就是今天）；
  - `已结束`（活动日期在今天之前）。
- 每个节点有 `编辑`、`查看相册`、`删除`。

#### 2.2 倒计时

- 顶部是倒计时卡片，每张显示「距离 X」「N 天」与截止日；`还有 N 天` 为未到，`天（已过去）` 为已过。
- 工具栏：`＋ 添加倒计时`、`🔄 刷新`、`从 Excel 表格批量导入`、`导出 EXCEL 表格`。
- 下方是 `⏳ 倒计时列表` 时间轴，每个节点可 `编辑`、`删除`。
- 没有倒计时时显示 `暂无倒计时，点击「添加倒计时」开始`。

### 3. 新增活动

`＋ 新增活动` 打开 `新增活动` 弹窗：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 时间 | 是 | 活动日期 |
| 主题 | 是 | 如 `主题班会` |
| 地点 | 否 | 如 `教室` / `操场` / `多媒体室` |
| 参与人员 | 否 | 如 `全班同学` / `张三、李四` |
| 简介 | 否 | 活动内容说明 |

`确认保存` 后出现在时间轴，状态按日期自动判定。

`编辑` 复用同一弹窗，弹窗左下角的 `删除` 会先弹确认，确认文案为「确定删除活动「…」吗？」。

### 4. 添加倒计时

`＋ 添加倒计时` 打开 `添加倒计时` 弹窗：

- **名称**（必填）：如 `期末考试` / `放假` / `高考`；
- **截止日**（必填）；
- **包含截止日当天**：勾选后当天视为剩余 1 天。

保存后卡片出现在页面顶部；截止日已过时显示为已过去的天数，不再显示「还有」。

### 5. 从 Excel 表格批量导入

两个标签页的工具栏都有 `从 Excel 表格批量导入`，按当前标签页写入对应数据；`新增活动` / `添加倒计时` 弹窗左上角也有同一入口（编辑已有记录时不显示）：

- **日常活动**：必填 `主题`；可选 `时间`、`地点`、`参与人员`、`简介`。`时间` 留空的活动不会出现在时间轴里。
- **倒计时**：必填 `名称`、`截止日`；可选 `包含这一天`（`是`/`否`、`true`/`false`、`1`/`0` 均可）。
- 导出的 `状态`、`剩余天数` 是派生列，导入时忽略。
- 导入为追加合并，不会覆盖已有活动或倒计时。

> **易错**：在倒计时页签导入活动列会导致缺少 `名称`/`截止日` 而报错，导入前先切到对应标签页。

格式与其它限制见 [32 导入导出](./32-import-export.md)。

### 6. 查看相册与导出

- `查看相册` 当前会跳到 `班级相册` 页面，由用户自行找对应相册；活动与相册暂未建立一对一关联。
- `📥 导出活动` 导出活动列表；`导出 EXCEL 表格` 导出倒计时列表。无数据时直接提示「暂无活动可导出」/「暂无倒计时可导出」，不弹格式面板。
- 导出格式清单见 [32 导入导出](./32-import-export.md)。

### 7. 撤销与易错

- 活动与倒计时的增删改各自独立进入撤销记录；`Ctrl+Z` 作用于当前标签页。
- 删除弹窗确认后立即生效，`Ctrl+Z` 可以退回最近一次删除。

> **易错**：活动的「状态」由日期决定，不由手工标记。补录旧活动时日期要填真实日期，否则会显示成 `进行中`。

> **易错**：倒计时的「已过去」不会自动隐藏，需要手工删除；长期不清理会让列表变长。

> **建议**：开学时把考试、放假、重大活动一次建好倒计时，倒计时页就成了一份日期看板。
