# 22 · AI 助手

## 前言

- **适用对象**：希望用 AI 查询统计、整理数据、生成图表的用户
- **本篇解决的问题**：配好模型、分清「全部审批 / 完全权限」、会确认写入提案、会用技能与附件
- **前提条件**：已登录；有可用的大模型服务商 API Key；需要联网

---

## 具体方法

### 1. 使用范围

想快速查「上学期谁请假最多」、把一段名单整理成表格、根据数据生成图表、批量修改某些字段时。

入口：`AI 助手`。

> **建议**：第一次使用先只做提问类操作（查询、统计、解释），确认回答质量后再尝试写入类操作。

### 2. 第一次配置

1. 进入 `AI 助手`，点 `设置` 打开 `🧠 AI 助手设置`。
2. 打开 `启用 AI` 开关。
3. `密钥管理` 右侧点 `添加模型`：
   - **服务商**：`DeepSeek（推荐）`、`Kimi（月之暗面）`、`通义千问`、`智谱清言`、`OpenAI`、`自定义（OpenAI 兼容）`；
   - **模型名称**：仅用于识别，如 `主模型`；
   - **模型名**：如 `deepseek-v4-flash`；点 `识别` 可从服务商拉取可用模型下拉，也可 `手填`；
   - **Base URL**：选择服务商后默认自动填充，自定义服务商需要自己填；
   - **API Key**：同一服务商已配置过可留空复用。
4. 点 `确定` 会自动检测连通性，通过后才保存。
5. 回到设置页，卡片上的 `当前` 标记表示正在使用的模型；点其它卡片可切换，切换时同样会验证连通。
6. 卡片上的 `推理` 勾选控制思考模式（DeepSeek / 智谱 / 通义支持）。

设置页还可以控制 `在其他页面显示 AI 助手小窗`：开启后，除登录页与 AI 助手页面本身外，其他页面右下角会显示悬浮图标，点开即可对话；关闭后只保留 AI 助手页面入口。该开关默认开启。

密钥只保存在本机数据库；对话内容由本机程序直接发往所选服务商，班集没有自己的中转服务器。

### 3. 对话界面

- 顶部：`数据管理`、`设置`，以及对话列表与 `新建对话` 两个图标按钮。
- 输入区上半是输入框，下半是工具行：
  - 左：`截屏`、`附件`、权限挡位；
  - 右：`模型` 快捷切换、`发送` / `中断`。
- 输入框占位提示：`输入问题，回车发送（Shift+Enter 换行）；打「/」选择技能`。
- 新对话没有消息时显示欢迎空态与示例问题。
- 回复以流式方式出现；点 `中断` 停止本次回复，已生成的内容保留。

#### 3.1 附件与截屏

- `附件` 支持图片、PDF、Word、PPT、Excel、文本；可直接粘贴图片或文件。
- 一次只携带一个附件，多文件粘贴以第一个为准。
- `截屏` 会先隐藏窗口截取整屏，再铺满屏幕供框选区域，`确定` 后作为 `截屏.png` 发给 AI。
- 附件显示为一张小卡片，可点 `✕` 移除。

#### 3.2 联网搜索

- 工具行的 `联网` 开关仅在 DeepSeek 模式下可用，其它服务商置灰。
- 开启后 AI 可查最新网页信息；关闭时只用模型已有知识。开关状态会记住，下次打开沿用。

### 4. 写入权限与提案

写入类操作（新增、修改、删除数据）有两种挡位：

| 挡位 | 行为 |
| --- | --- |
| `全部审批` | 每次改数据都先生成提案，等待确认 |
| `完全权限` | 提案自动执行，不再逐次确认 |

- 切到 `完全权限` 前会弹确认，提示数据可能被意外删除或损坏；确认后才切换。切回 `全部审批` 立即生效。
- 提案以浮窗出现，按钮为 `确认执行` 与 `✕`；`✕` 表示不执行，数据不变。
- 执行时可点右侧 `数据改动` 抽屉查看明细：
  - 按文件 / 按表列出，带 `+新增` / `-删除` 统计；
  - 行式表显示增删的行或字段变更（批量修改显示旧值 → 新值）；
  - 课表、座位、权重等网格表显示写入的格子；
  - 技能 md 文件显示行级差异；
  - 每项与每行都有 `跳转`，可直达对应页面定位。

> **易错**：`完全权限` 下提案会自动执行，浮窗一闪而过。不确定 AI 会改什么时，保持 `全部审批`。

> **易错**：看完提案直接关掉浮窗不等于执行；只有在 `全部审批` 下点 `确认执行` 才写入。

### 5. 撤销 AI 的改动

- AI 的写入同样登记撤销记录，可在 `设置 → 撤销记录` 查看与按条撤销。
- 同一次执行产生的多条改动会打上同一批次标记，可在 AI 对话里要求整批回退。
- `Ctrl+Z` 只作用于当前页面，AI 的跨表改动建议用 `设置 → 撤销记录` 处理。

### 6. 技能与长期记忆

- **技能**是放在技能目录里的 Markdown 指令文件，用来固定一套做事方式（如「按班级花名册格式整理」）。
- 输入框打 `/` 弹出技能候选，按技能 md 文件名匹配；选中后成为可移除的小标签，随本轮请求生效。
- `数据管理` 里可以：
  - 管理聊天记录：逐条 `导出`、`删除`（删除不可恢复）；
  - 管理 Markdown 文件：`新增文件`、`编辑`、`删除`、`导出`，并可 `打开文件夹` 查看技能目录；
  - **AI 记忆文件**：系统长期记忆，名称固定、`删除` 按钮置灰不可点，可 `编辑` 与 `导出`。

> **建议**：需要 AI 长期记住的偏好（如称呼习惯、输出格式）写进 AI 记忆文件；一次性的要求写进当轮提问或技能。

> **易错**：删除聊天记录与技能文件都不可恢复，删除前可先 `导出`。

### 7. 未启用与常见提示

- 未启用时页面显示统一空态「AI 助手尚未启用」，点下方 `去设置` 按钮打开设置弹窗，填写 API Key 并启用。
- 模型不可用或密钥失效时，添加/切换模型会在测试连通环节失败并给出原因；按提示检查密钥、Base URL 与网络。
- 服务商超时或网络不佳时，回复可能中断；可重新发送或换模型。
