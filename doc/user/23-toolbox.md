# 23 · 工具箱浮窗

## 前言

- **适用对象**：上课时需要在桌面随时计时、点名、截图、圈画的用户
- **本篇解决的问题**：知道浮窗怎么开、四个工具怎么用、退出后如何重新启用
- **前提条件**：已在 `设置 → 工具箱设置` 打开 `是否启用工具箱`

---

## 具体方法

### 1. 使用范围

课堂计时、随机点名、把屏幕上某块内容截图或圈出来讲解时。

### 2. 打开与关闭

1. 进入 `设置 → 工具箱设置`，打开 `是否启用工具箱`。
2. 打开后，桌面上出现一个悬浮图标；开关即时生效，不需要重启。
3. 左键点图标展开功能菜单，再次点击收起；菜单外点击也会收起。
4. 拖动图标或面板可改变浮窗位置，下次打开会回到上次位置。
5. 关闭方式有两种：
   - 菜单底部 `退出工具箱`：二次确认「确认退出工具箱吗？下次启动需要在设置里重新启用。」，确认后浮窗消失，同时设置里的开关变为关闭；
   - 右键浮窗图标：呼出原生菜单，`本次退出` 只隐藏浮窗，不改变设置开关。

> **易错**：用菜单里的 `退出工具箱` 退出后，重启班集也不会再出现浮窗，需要回设置里重新打开开关。

### 3. 四个工具

功能菜单有四项：`计时器`、`点名器`、`截图`、`注释`。

#### 3.1 计时器

- 两个模式：`正计时`、`倒计时`。
- `开始` 后按钮变为 `暂停`；另有 `重置` 与 `关闭`。
- 倒计时先设置时长，再开始。
- 计时只在浮窗内进行，关闭工具后本次计时结束。

#### 3.2 点名器

- 打开即开始滚动，学号与姓名一起变化，不需要再点开始。
- `完成` 停在当前学生上；`关闭` 退出点名器。
- 名单来自 `学生管理` 的学生信息；名单为空或加载失败时会给出提示。

#### 3.3 截图

- 打开后自动截取当前屏幕，显示保存路径，`完成` 保存。
- 保存目录默认为系统「图片」文件夹下的 `screenshots`（即 `Pictures\screenshots`），数据目录不在其中；可在 `设置 → 保存路径设置` 调整，留空恢复默认。
- 截图过程中窗口会临时隐藏自身，避免把浮窗拍进画面。

#### 3.4 注释

- 在截屏画面上用 `画笔` 标注，用 `橡皮擦` 擦除；画笔与橡皮擦都有 `粗细` 二级菜单。
- `保存` 后进入保存页，显示保存路径，`完成` 关闭；`取消` 放弃本次注释。
- 注释与截图共用同一个保存目录。

### 4. 常见情况

- 浮窗始终置顶、不在任务栏显示，适合在演示或讲课中随手调用。
- 关闭主窗口时，`关闭班集` 菜单可单独选择「关闭主窗口和工具箱」，见 [01 安装与首次启动](./01-install-and-first-run.md)。
- 浮窗与桌面小组件可以同时存在，互不影响。

> **建议**：上课前先打开一次点名器确认名单已加载，避免课上等待。

> **建议**：截图与注释都落在同一个目录，定期清理或在 `保存路径设置` 里指到更容易找到的位置。
