# 24 · 桌面小组件

## 前言

- **适用对象**：希望在桌面上常驻看到课程、值日、倒计时与人数情况的用户
- **本篇解决的问题**：知道怎么启用、面板上有什么、8 格常用软件怎么维护
- **前提条件**：已在 `设置 → 桌面小组件设置` 打开 `启用桌面小组件`；建议先有课程表、值日与倒计时数据

---

## 具体方法

### 1. 使用范围

上课前看一眼下节课、放学前核对今日值日、随时看到班级人数与最近倒计时。

### 2. 启用与位置

1. 进入 `设置 → 桌面小组件设置`，打开 `启用桌面小组件`；开关即时生效。
2. 面板出现在桌面右侧，宽度固定，高度约占屏幕 95%，可以拖动改变位置。
3. 拖动后的落点会被记住，重启班集或组件重建后回到该位置；位置文件损坏或首次运行时回到默认位置。
4. 面板常驻桌面最底层：被其它窗口盖住、不进入 Alt+Tab、`Win+D` 也不隐藏，但仍可点击与拖动。
5. 关闭方式：`关闭班集` 菜单里的「关闭主窗口和桌面组件」会一并关闭；设置开关关闭后组件消失。

### 3. 面板内容

| 区域 | 内容 | 点击后 |
| --- | --- | --- |
| 顶部 | 时钟 | — |
| 顶部 | 最近倒计时（名称与剩余天数） | 跳到 `班级活动 → 倒计时` |
| 中部 | 下一节课 | 跳到 `课程表` |
| 左栏 | 今日课程 | 跳到 `课程表` |
| 右栏 | 今日值日 | 跳到 `值日管理` |
| 右栏 | 人数情况（全班 / 在校 / 请假） | 跳到 `请假管理` |

- 点击任一区块会唤醒主窗口并跳到对应页面，不会新开窗口。
- 数据加载失败时该区块显示为空，不影响其它区块。

### 4. 8 格常用软件

- 面板底部固定 8 个槽位（4 列 × 2 行）。
- 空槽点击即可添加；也可以把桌面上的快捷方式、文件夹或文件直接拖进槽位。
- 满 8 个后不再出现空槽入口；后端同样最多接受 8 个。
- 点击图标启动对应软件或打开对应文件/文件夹。
- 图标可直接拖动排序，轻点仍是启动；拖动超过几个像素才进入排序。
- 常用软件列表写入本机设置，重启后保留。

> **易错**：把不存在的快捷方式拖进来后，点击会无反应；原文件被移动或删除时，需要重新拖入。

> **建议**：8 格只放课上真正常用的工具（如课件、计时、播放器），避免变成第二个桌面。

### 5. 外观与数据

- 面板的日间 / 夜间配色跟随 Windows 系统的深浅色设置，实时切换；不与班集应用内主题联动。
- 面板显示的课程、值日、人数、倒计时都来自本机数据，未登录或后端未就绪时这些区块会暂时为空。

### 6. 常见情况

- 面板不在任务栏显示，想临时收起可用 `关闭班集` 菜单中的「关闭主窗口和桌面组件」。
- 非 Windows 系统或桌面层级能力不可用时，面板会退回普通窗口：可点、可拖，但不再常驻最底层。
- 拖不动或点击后跳到错误页面时，先确认主窗口未处于未登录状态。
