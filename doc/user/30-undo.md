# 30 · 撤销与重做

## 前言

- **适用对象**：担心误改、误删数据，希望操作后能退回的用户
- **本篇解决的问题**：知道哪些操作能撤、快捷键怎么用、撤销记录在哪里、保留多久
- **前提条件**：已登录

---

## 具体方法

### 1. 使用范围

改错单元格、删错行、智能排表结果不满意、AI 批量改动需要回退时。

### 2. 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 撤销 | `Ctrl+Z` |
| 重做 | `Ctrl+Shift+Z` 或 `Ctrl+Y` |

- 只在表格 / 页面区域生效；焦点在输入框、文本域时，快捷键走系统或浏览器的文本撤销，不会改动数据。
- 一次只作用于**当前页面当前激活的那张表**。多个页面同时开着时，只有最近激活的页面响应。
- 同一页面有多个标签（如活动 / 倒计时）时，撤销作用于当前标签。

### 3. 哪些操作可撤

- 表格中的单元格修改、行内新增、删除行、剪切 / 粘贴；
- 网格表的单格修改、整行 / 整列交换等整块变更；
- 座位、值日、课程表的表内容改动；
- 分组结构的增删小组、增删成员、成员排序、智能分组应用；
- 加分、请假、班费、活动、倒计时的增删改；
- 相册的添加、删除、排序与照片删除；
- AI 执行写入提案后产生的改动。

> **易错**：撤销是「一条一条退」，不是「回到上次打开软件的样子」。连续改了很多格，需要连按多次 `Ctrl+Z`。

> **易错**：切换到别的页面后按 `Ctrl+Z`，撤的是新页面的最近一步，不是刚离开的页面。

### 4. 撤销记录

路径：`设置 → 撤销记录`。

- 记录按表分组，每组显示「N 步可撤销」。
- 每条记录显示操作说明与 `撤销` 按钮；已撤销的记录带 `已撤销` 标记。
- 撤销后界面会提示「已撤销：…」，并刷新对应页面数据。
- `清空所有撤销记录` 会删除全部记录，确认后不可恢复。
- 记录保存在本机数据库，**关闭软件、重启后仍然保留**；每张表只保留最近 50 步。

### 5. 常见失败与限制

- 撤销时若目标数据已被其它操作删除，会提示「撤销失败，可能目标数据已被删除」。
- 记录登记失败时，操作本身已完成，但会提示「…已完成，但本次无法撤销」；此时只能手工改回。
- 账号与安全等级、学期设置、主题、保存路径、数据目录等**设置类操作不在撤销范围**。
- 清空撤销记录后，之前的操作都不能再退。

> **建议**：大批量操作（导入、智能排表、AI 写入）之前先导出或备份，撤销只是第一道保险。

> **建议**：误删后先到撤销记录里找对应条目；找不到再考虑从备份恢复。
