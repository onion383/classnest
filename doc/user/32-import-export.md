# 32 · 导入导出

## 前言

- **适用对象**：需要从 Excel 批量录入数据、或把页面数据导出成文件交给别人的用户
- **本篇解决的问题**：分清「Excel 导入」与「从模板导入」，知道各导出格式的差别与限制
- **前提条件**：导入需要准备表格文件；导出需要选择保存位置

---

## 具体方法

### 1. 两种「导入」的区别

| 说法 | 含义 | 出现在 |
| --- | --- | --- |
| `从 Excel 表格批量导入` / `从文件导入数据` | 读取 Excel 文件，把行合并进当前表 | 学生信息、班费记录、加分管理、请假记录、活动与倒计时、班干部、分组、课程表、座位、值日（各页单个添加弹窗左上角也有同一入口） |
| `从模板导入` / `从实行导入` | 把内部另一张表整体复制过来，不涉及 Excel | 座位、值日、课程表、分组等 |

本篇第 2 节讲前者；后者的用法见各页面篇目。

### 2. Excel 导入

#### 2.1 入口

- `学生管理 → 学生信息 → 从 Excel 表格批量导入`
- `班费管理 → 从 Excel 表格批量导入`
- `加分管理 → 今日加分 / 加分统计 → 从 Excel 表格批量导入`（按右上角 `加分对象` 决定导入个人还是小组）
- `请假管理 → 请假记录 → 从 Excel 表格批量导入`
- `班级活动 → 日常活动 / 倒计时 → 从 Excel 表格批量导入`（按当前标签页切换表头）
- `学生管理 → 班干部管理 → 从 Excel 表格批量导入`
- `分组管理 → 从 Excel 表格批量导入`（写入当前维度）
- `课程表 → 实行课表 / 一般课表 → 从 Excel 表格批量导入`
- `座位管理 → 从 Excel 表格批量导入`（写入当前显示的临时表或模板表）
- `值日管理 → 从 Excel 表格批量导入`（写入当前显示的值日表或值日模板）
- `课程表 → 设置（作息时间设置） → 从 Excel 表格批量导入`
- `值日管理 → 设置（值日设置） → 从 Excel 表格批量导入`

> 学生信息、班费记录、加分记录（今日时间轴与统计表）、请假记录、实行/一般课表、值日表、分组管理在**空表/空状态**时，里面还会多出一个暖色的 `从 Excel 表格批量导入` 按钮，点它打开的就是同一个导入弹窗，不必再回工具栏找入口。课程表与值日表的空状态只在尚未配置作息/劳动项目时出现，这时应先完成设置再导入。

> 单个添加弹窗（`添加学生`、`添加记录`、`加分登记`、`请假登记`、`新增活动`、`添加倒计时`、`添加职务`、`添加小组`）的左上角也有同一个 `从 Excel 表格批量导入` 按钮：点击后会关闭单条录入弹窗，直接打开批量导入弹窗；编辑已有记录时不显示该按钮。

#### 2.2 步骤

1. 弹窗顶部 `下载标准导入表` 旁的 `点击下载` 按钮会**现场生成**一份 `.xlsx`（不是预置文件）：第 1 行是合并居中的标题，第 2 行是表头，下面 20 行空白数据区，全部带细框线。照着填识别成功率更高；使用其他格式的表格也可以导入。
2. 点按钮打开 `从文件导入数据`，点击选择文件或把文件拖到弹窗。
3. 文件自动解析并显示预览表格；只读取**第一个工作表**。
4. 表头会自动识别：优先取「下一行有内容、非空列最多」的一行；表头下面暂时空着（如标准导入表）时，退而取非空列最多的一行——合并居中的标题只有一格，会被自动跳过。
5. 页面上会提示因缺少受保护字段被过滤的条数。
6. 预览区只显示前若干行，但 `导入并合并保存` 会写入全部行。行状表用普通表格预览；课程表、座位、值日这类矩阵表用网格预览，讲台行、走廊列等特殊格式与页面上的主表保持一致。
7. 确认后写入，原有数据保留，新行合并进来。

#### 2.3 限制

- 文件体积上限 **10MB**，超过直接拒绝并提示。
- 学生导入需要 `学号`、`姓名`；班费导入需要 `收支编码`。缺少这些字段的行会被过滤。
- 加分导入：个人模式需要 `姓名`（`学号` 可选，用于精确匹配学生）；小组模式需要 `小组`。
- 请假导入：需要 `姓名`、`开始时间`、`结束时间`；`学号` 可选（用于匹配学生并自动带出联系电话）。
- 活动导入需要 `主题`；倒计时导入需要 `名称`、`截止日`。
- 班干部导入需要 `职务`；`上级职务` 按名称匹配，`担任学生` 多人用顿号/逗号/空格分隔。
- 分组导入需要 `小组`、`姓名`；`备注` 可选。
- 作息时间设置导入：`时段`、`类型`、`名称`、`开始时间`、`结束时间`（前四项必填，时间用 `HH:mm`）。
- 值日设置导入：`劳动项目`（必填）、`人数`、`辛苦度`。
- `课程表`、`座位表`、`值日表` 属于**矩阵导入**：按文件里的行号/项目名与列头逐格匹配当前显示的表格，见 2.4。
- 只解析首个工作表，多工作表文件需要先拆开或合并到第一张表。
- 导入是「合并」，不是「覆盖」；重复行需要用 `去除重复数据` 清理。

> **易错**：把标题行做成合并单元格的复杂表头时，自动识别可能选错行；导入前把表头整理成单行最稳妥。

> **易错**：导入前未备份。大批量导入后想整体回退，只能靠撤销记录或数据库备份。

#### 2.4 矩阵导入（课程表 / 座位 / 值日）

这三页导出的本身就是「行 × 列」的矩阵，导入时按表头逐格匹配当前显示的表格：

- **课程表**：首列 `行号` 是节次名称，其余列是星期；只写 `学习` 行，`休息`/`大课间` 行不接收数据。
- **座位表**：首列 `行号` 形如 `第1行`，其余列是 `列1`、`列2`…；`走廊` 列不接收数据。
- **值日表**：首列 `项目` 是劳动项目名，其余列是星期；多人用顿号/逗号/空格分隔。

匹配规则：

- 行号/项目名必须与当前页面一致；有一个对不上就整批不写入，并提示第几行。
- 只覆盖文件里出现的格子：文件里的空单元格会清空该格，未出现在文件里的行保持原样。
- 课程表 / 座位表 / 值日表导入成功后都可以用 `Ctrl+Z` 撤销。
- 矩阵导入写的是「当前显示」的那张表（如实行课表、临时座位表、当前值日表），不会同时改模板。

### 3. 导出面板

各页面的 `导出…` 按钮都会打开同一套导出面板：

1. **选择要导出的列**（或选择要导出的小组）。
2. **导出行**：`全部行` 或 `仅选中行 (N)`；没有勾选行时「仅选中行」不可用。
3. **导出格式**。
4. **文件名**，再选择保存位置。
5. `导出`；按钮置灰并显示 `导出中 N%`，完成后提示「已成功导出 …」。

> **说明**：导出期间按钮与「取消」都会置灰，避免重复点击；在系统「保存文件」窗口中点取消、或保存失败时，导出面板不会关闭，可以调整文件名/格式后直接重试。

### 4. 格式对照

| 格式 | 适合 | 说明 |
| --- | --- | --- |
| `HTML 表格 (.html)` | 发给别人直接看 | 带表格样式，浏览器可打开；内嵌简易表格组件，可拖拽调换行列（仅前端） |
| `Excel (.xlsx) - 带边框` | 继续加工、上报 | 全表细框线、纯白底，不带单元格颜色 |
| `CSV (.csv) - 无样式` | 导入其它系统 | 纯文本表格，无格式 |
| `Markdown 文档 (.md)` | 写文档、进知识库 | 表格语法 |
| `纯文本 (.txt)` | 快速查看、复制 | 以制表符分隔 |
| `JSON 数据 (.json)` | 备份、程序处理 | 保留字段结构 |
| `图片 (.png)` | 张贴、发群 | 整表截图 |
| `PDF 文档 (.pdf)` | 打印、留档 | A4 横向黑白分页排版，表头与各行均不填底色 |

个别入口会屏蔽部分格式：

- `导出相册索引` 不出图片格式；
- `导出分组` 不出图片格式。

### 5. 各页面的导出入口

| 页面 | 按钮 |
| --- | --- |
| 学生信息 | `导出 Excel` |
| 班干部 | `导出 Excel` |
| 座位管理 | `导出 Excel`（座位表、权重表、座位指数、周记录） |
| 课程表 | `导出 Excel`（实行 / 一般 / 历史） |
| 值日管理 | `导出值日表`、`导出 Excel`（权重、指数、记录） |
| 分组管理 | `导出分组` |
| 加分管理 | `📥 导出个人加分` / `📥 导出小组加分` |
| 请假管理 | `导出今日表`、`导出请假记录`、请假统计导出 |
| 班费管理 | `导出 Excel` |
| 班级相册 | `导出相册索引` |
| 班级活动 | `📥 导出活动` / `导出 EXCEL 表格`（倒计时） |

> **建议**：需要给别人看时用 HTML 或 PDF；需要继续统计时用 Excel；需要留档与迁移时再加一份 JSON。

### 6. 易错与建议

> **易错**：导出的「仅选中行」依赖表格勾选。筛选后勾选，导出的仍是实际选中的行，不是「筛选后看见的全部行」。

> **易错**：图片与 PDF 导出的是当前列的排版，列太多时会挤在一起；导出前精简列。

> **建议**：期末把关键页面各导出一份 Excel，再配合 `设置 → 账号管理 → 导出数据库` 一起留档。
