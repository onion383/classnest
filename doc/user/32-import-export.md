# 32 · 导入导出

## 前言

- **适用对象**：需要从 Excel 批量录入数据、或把页面数据导出成文件交给别人的用户
- **本篇解决的问题**：分清「Excel 导入」与「从模板导入」，知道各导出格式的差别与限制
- **前提条件**：导入需要准备表格文件；导出需要选择保存位置

---

## 具体方法

### 1. 两种「导入」的区别

| 说法 | 含义 | 出现在 |
| --- | --- | --- |
| `从 Excel 导入` / `从文件导入数据` | 读取 Excel 文件，把行合并进当前表 | 学生信息、班费记录 |
| `从模板导入` / `从实行导入` | 把内部另一张表整体复制过来，不涉及 Excel | 座位、值日、课程表、分组等 |

本篇第 2 节讲前者；后者的用法见各页面篇目。

### 2. Excel 导入

#### 2.1 入口

- `学生管理 → 学生信息 → 从 Excel 导入`
- `班费管理 → 从 Excel 导入`

#### 2.2 步骤

1. 点按钮打开 `从文件导入数据`，点击选择文件或把文件拖到弹窗。
2. 文件自动解析并显示预览表格；只读取**第一个工作表**。
3. 表头会自动识别：在前 10 行内找非空列最多、且下一行有内容的那一行，跳过标题行与空行。
4. 页面上会提示因缺少受保护字段被过滤的条数。
5. 预览区只显示前若干行，但 `导入并合并保存` 会写入全部行。
6. 确认后写入，原有数据保留，新行合并进来。

#### 2.3 限制

- 文件体积上限 **10MB**，超过直接拒绝并提示。
- 学生导入需要 `学号`、`姓名`；班费导入需要 `收支编码`。缺少这些字段的行会被过滤。
- 只解析首个工作表，多工作表文件需要先拆开或合并到第一张表。
- 导入是「合并」，不是「覆盖」；重复行需要用 `去除重复数据` 清理。

> **易错**：把标题行做成合并单元格的复杂表头时，自动识别可能选错行；导入前把表头整理成单行最稳妥。

> **易错**：导入前未备份。大批量导入后想整体回退，只能靠撤销记录或数据库备份。

### 3. 导出面板

各页面的 `导出…` 按钮都会打开同一套导出面板：

1. **选择要导出的列**（或选择要导出的小组）。
2. **导出行**：`全部行` 或 `仅选中行 (N)`；没有勾选行时「仅选中行」不可用。
3. **导出格式**。
4. **文件名**，再选择保存位置。
5. `导出`；成功后提示「已成功导出 …」。

### 4. 格式对照

| 格式 | 适合 | 说明 |
| --- | --- | --- |
| `HTML 表格 (.html)` | 发给别人直接看 | 带表格样式，浏览器可打开 |
| `Excel (.xlsx) - 带边框` | 继续加工、上报 | 带边框，最通用 |
| `CSV (.csv) - 无样式` | 导入其它系统 | 纯文本表格，无格式 |
| `Markdown 文档 (.md)` | 写文档、进知识库 | 表格语法 |
| `纯文本 (.txt)` | 快速查看、复制 | 以制表符分隔 |
| `JSON 数据 (.json)` | 备份、程序处理 | 保留字段结构 |
| `图片 (.png)` | 张贴、发群 | 整表截图 |
| `PDF 文档 (.pdf)` | 打印、留档 | 分页排版 |

个别入口会屏蔽部分格式：

- `导出相册索引` 不出图片格式；
- `导出分组` 不出图片格式。

### 5. 各页面的导出入口

| 页面 | 按钮 |
| --- | --- |
| 学生信息 | `导出 Excel` |
| 班干部 | 页面内导出 |
| 座位管理 | `导出 Excel`（座位表、权重表、座位指数、周记录） |
| 课程表 | `导出 Excel`（实行 / 一般 / 历史） |
| 值日管理 | `导出值日表`、`导出 Excel`（权重、指数、记录） |
| 分组管理 | `导出分组` |
| 加分管理 | `📥 导出个人加分` / `📥 导出小组加分` |
| 请假管理 | `导出今日表`、`导出请假记录`、请假统计导出 |
| 班费管理 | `导出 Excel` |
| 班级相册 | `导出相册索引` |
| 班级活动 | `📥 导出活动` / `导出 EXCEL 表格`（倒计时） |

> **建议**：需要给别人看时用 HTML 或 PDF；需要继续统计时用 Excel；需要留档与迁移时再加一份 JSON。

### 6. 易错与建议

> **易错**：导出的「仅选中行」依赖表格勾选。筛选后勾选，导出的仍是实际选中的行，不是「筛选后看见的全部行」。

> **易错**：图片与 PDF 导出的是当前列的排版，列太多时会挤在一起；导出前精简列。

> **建议**：期末把关键页面各导出一份 Excel，再配合 `设置 → 账号管理 → 导出数据库` 一起留档。
