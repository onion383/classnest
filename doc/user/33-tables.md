# 33 · 表格通用交互

## 前言

- **适用对象**：所有使用动态表格页面的用户
- **本篇解决的问题**：一次学会勾选、编辑、拖拽、右键菜单、筛选排序与新增行，减少逐页摸索
- **前提条件**：已登录；页面已有数据

---

## 具体方法

### 1. 适用范围

学生信息、班干部、班费、请假记录、加分记录等使用动态表格的页面，交互基本一致。座位、课表、值日等网格表只用其中的一部分（见各自篇目）。

### 2. 勾选与批量操作

- 每行首列是复选框；表头首列是 `全选` 复选框。
- 全选只作用于**当前可见行**：筛选或搜索隐藏的行不会被勾上。
- 勾选后，工具栏的 `批量删除 (N)` 可一次删除选中行；`N` 是选中数量。
- 部分页面把整列勾选框隐藏（如只读展示页），此时没有批量操作。

### 3. 编辑单元格

- 双击单元格进入编辑，失焦或回车保存。
- 下拉类字段在编辑时变为下拉框；日期类字段变为日期选择器。
- 受保护字段（列名后带 `*`，如 `学号`、`姓名`）不可删除，部分页面也不允许改列。
- 编辑立即写入；保存失败会提示，界面不会假装已保存。

### 4. 新增行

- 表格底部有 `＋ 点击添加一行`；存在新增行时变为 `取消添加一行`。
- 新增行在首列显示 `自动`，填写后保存落入正式数据。
- 新增行已填写内容时点取消，会弹 `放弃新增行` 确认，确认后不保存。

### 5. 列操作

- 列标题左侧有 `⠿` 手柄，按住可拖动整列换位置。
- 表头右键菜单：
  - `修改列名`
  - `在左侧插入列` / `在右侧插入列`
  - `删除本列`
  - 受保护字段显示 `删除本列（受保护）` 并提示不可删除
- 列宽按内容自动适配，不需要手动拖宽。
- 列顺序与列名会保存，下次进入保持一致。

### 6. 行操作

- 行首 `⠿` 手柄按住可拖动整行调整顺序；松手后新顺序即保存。
- 行右键菜单：
  - `上移`、`下移`
  - `📋 粘贴到上方 (N)` / `📋 粘贴到下方 (N)`（剪贴板有内容时出现）
  - `在上面插入行`、`在下面插入行`
  - `✂️ 剪切 (N)`
  - `🗑️ 删除 (N)`
- 剪切会把行移入剪贴板（界面中暂时消失），粘贴后落到目标位置；`N` 为涉及的行数。
- 新增行上右键只有 `取消新行`。

> **易错**：剪切后没有粘贴就离开页面，剪贴板内容可能失效；剪切后尽快粘贴到目标位置。

> **易错**：拖动排序会直接改变保存顺序。按时间排的记录表（如请假明细）通常禁用了行拖动，看到没有 `⠿` 手柄是正常的。

### 7. 筛选、排序与搜索

- 列名旁的按钮：未筛选时是放大镜，已筛选时是漏斗，提示为「列名：筛选 / 排序」或「列名：已筛选（点击修改）」。
- 点开面板可以：
  - 选择升序 / 降序；
  - 按值勾选要显示的内容；
  - 清除该列筛选。
- 点列名本身会展开该列的关键字搜索。
- 筛选后无数据时显示 `没有符合筛选条件的数据`；关键字搜索无结果时显示搜索空态并给 `清除搜索`。
- 刷新页面不会自动清掉筛选；需要看全部数据时到面板里清除。

> **建议**：先筛选再勾选批量操作，能避免误删看不见的行。

### 8. 撤销

表格里的修改、增删、粘贴都会进入撤销记录，`Ctrl+Z` 可退一步，详见 [30 撤销与重做](./30-undo.md)。
