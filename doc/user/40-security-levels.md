# 40 · 账号与安全等级

## 前言

- **适用对象**：担心数据外泄、或需要在一台电脑上区分多个账号的用户
- **本篇解决的问题**：四档安全等级各自意味着什么；等级之间能否切换、切换时会发生什么；多账号如何共存
- **前提条件**：已安装并完成首次引导；切换等级前已知晓当前账号的登录密码

---

## 具体方法

### 1. 四档安全等级

注册账号时在 `注册账号` 页顶部的下拉框选择等级，之后可在 `设置 → 账号管理` 修改。

| 等级 | 界面称呼 | 数据库 | 登录方式 | 适用情形 |
| --- | --- | --- | --- | --- |
| 一 | `明文模式（不加密）` | 明文，可被任何能拿到文件的人打开 | 只需账号 | 只在完全可信的电脑上使用；便于自己手工看库 |
| 二 | `无密码模式（加密，免密码登录）` | 加密 | 只需账号，不输密码 | 电脑有他人共用、但不想每次输密码 |
| 三 | `普通密码模式（加密 + 登录密码）` | 加密 | 账号 + 密码（≥6 位） | 常规推荐档位 |
| 四 | `超级隐私模式（密码 + 恢复词）` | 加密，库钥匙由密码与恢复词分别包裹 | 账号 + 密码；忘记密码时用恢复词 | 电脑可能被他人接触，且数据敏感 |

各档的差别集中在两处：**磁盘上的数据库是否加密**，以及**打开它需要什么**。界面内的显示、导出、AI 等功能在各档一致。

> **建议**：不清楚选哪档时用 `普通密码模式（加密 + 登录密码）`；需要更强保护再升到超级隐私模式。

### 2. 在哪里看与改

- 查看：`设置 → 账号管理`，页面上方显示当前用户名与安全等级。
- 修改：同一页的安全等级下拉框，选中目标等级后按提示完成。
- 注册时选择：`登录页 → 注册 → 注册账号` 页顶部下拉框。

### 3. 等级切换规则

切换不是「改一个标签」，会真实地重新加密或解密数据库。

| 当前 → 目标 | 需要提供 | 结果 |
| --- | --- | --- |
| 明文 → 无密码 | 无 | 先把明文库转换为加密库，登录仍不需要密码 |
| 明文 → 普通密码 / 超级隐私 | 新密码（≥6 位，连续输入两次） | 先把明文库转换为加密库，再按目标等级生效 |
| 无密码 → 明文 | 无 | 关闭加密，库转为明文保存 |
| 无密码 → 普通密码 / 超级隐私 | 新密码（≥6 位，连续输入两次） | 加密库保留，增加登录密码校验 |
| 普通密码 / 超级隐私 → 明文 / 无密码 | 当前密码 | 清除登录密码，库转换为明文（目标为明文时） |
| 普通密码 → 超级隐私 | 当前密码 | 生成新的 12 词恢复词，仅本次显示一次 |
| 超级隐私 → 普通密码 | 当前密码 | 关闭恢复词通道，改回仅密码解锁 |
| 普通密码 / 超级隐私 → 同档其它方向 | 当前密码 | 按上表规则逐项生效 |

要点：

- 从 `普通密码模式` 或 `超级隐私模式` 切出时，界面会要求验证当前密码；验证通过才会执行。
- 从 `明文模式` / `无密码模式` 升到需要密码的档位时，新密码要**连续输入两次**，两次一致才能提交，防的是首次设密码打错。忘记密码的退路随目标档位不同：`普通密码模式` 可在原机走「忘记密码 → 使用本机信息恢复」重设；`超级隐私模式` 不适用本机恢复，只能用 12 词恢复词。
- 目标为 `明文模式` 或 `无密码模式` 时会清空密码，之后登录不再要求密码。
- 从 `明文模式` 进入任意加密档时，程序会先做一次整库转换，耗时随数据量增长；转换期间页面不可操作。
- 进入 `超级隐私模式` 会生成新的恢复词，旧恢复词立即失效。切换后弹出的是**与注册时同一个恢复词窗口**：必须先点「下载文本」存到本地，再抄写前 3 个词，确认后窗口才关闭。
- 界面在关闭加密前会提示「关闭加密后…此操作不可逆」。

> **易错**：明文库可以被任何拿到文件的人直接打开。切到 `明文模式` 之前，先确认这台电脑没有他人使用，或已把整个数据目录放在受控位置。

> **易错**：进入 `超级隐私模式` 时显示的 12 词恢复词只出现一次，界面不提供再次查看。没有离线副本，忘记密码后只能依赖原机上已解锁的会话。

### 4. 多账号

- 每次 `注册账号` 都会新建一个独立的账号与独立数据库；不同账号的数据互不可见。
- 登录页输入不同账号即进入对应库，不需要切换文件。
- `从数据库登录` 用于按库文件定位本机已登记的某个账号，适合账号名记不清的场景；选中 `.db` 文件后会直接进入该库。

> **建议**：同一台电脑上按用途分账号（例如「本班」「兴趣班」），备份与删除都能按账号单独进行。

### 5. 修改密码、修改用户名与退出登录

- 修改密码：`设置 → 账号管理 → 修改密码`。**只有 `普通密码模式` 与 `超级隐私模式` 显示这个按钮**；`明文模式` / `无密码模式` 没有登录密码可改，按钮不出现，要给账号加密码请用同页的「安全等级」下拉切到需要密码的档位（切过去时连续输入两次新密码）。超级隐私模式下修改密码会同时更新密码通道，恢复词通道保持不变。
- 修改用户名：同一页的 `修改用户名`，只改显示与登录名，不影响库文件。`普通密码模式` / `超级隐私模式` 需输入当前密码；`明文模式` / `无密码模式` 不会出现密码框，直接改即可。
- 退出登录：`设置 → 账号管理 → 退出登录`，回到登录页。

超级隐私模式解出的库钥匙只在该次登录期间留在内存中，退出登录后即丢失，再次进入需要重新输入密码或恢复词。

> **易错**：退出登录前若正在使用 AI 或导入导出，相关操作会中断；退出后未保存的界面内编辑会丢失。

### 6. 常见情况

- 下拉框中的四个等级始终可选，选中后按第 3 节规则弹出对应窗口（验证当前密码 / 设置并确认新密码 / 展示恢复词）。
- 切换后登录方式立刻变化：例如从 `无密码模式` 升到 `普通密码模式` 后，下一次登录就要输入新密码。
- 切换失败并提示密码错误：密码验证在切换前进行，验证不通过时库保持原状。
