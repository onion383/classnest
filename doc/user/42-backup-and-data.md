# 42 · 备份与数据位置

## 前言

- **适用对象**：准备换电脑、重装系统、或需要为期末留档的用户
- **本篇解决的问题**：如何导出一份完整备份；换机与恢复的三种做法各自适用什么情形；升级/卸载会不会动数据
- **前提条件**：备份需要当前账号的登录密码（无密码账号可留空）；恢复只能从登录页发起

---

## 具体方法

### 1. 导出数据库（最稳的备份）

入口：`设置 → 账号管理 → 导出数据库`。

弹窗说明为「导出当前库（业务数据 + 应用设置 + 账号），换机后用对应的密码恢复」，包含：

- 全部业务数据（学生、座位、值日、课程表、班费、请假、加分、分组、活动、相册索引等）；
- 应用设置；其中主题偏好保存于本机界面设置，不随备份包走；
- 账号本身；
- AI 长期记忆。

操作步骤：

1. 在 `登录密码（未设密码可留空）` 填入当前登录密码；有密码账号留空时，界面会提示需要输入登录密码。
2. 数据库已加密时，可勾选 `数据库密码加密导出`：
   - 有密码账号：`数据库密码` 留空即默认使用账号登录密码；
   - 无密码账号：勾选后需另填一个导出密码，否则无法继续导出。
3. 点 `导出备份`，文件以 `<用户名>-backup.json` 保存到所选位置。
4. 成功后界面会提示导出成功，并说明备份文件与本次使用的数据库密码需要自行保管。

数据库未加密时，弹窗直接说明「当前数据库未加密，导出的备份包为明文，无需设置导出密码」。

> **易错**：备份文件与密码分开保存时，要保证两者以后都能找到。加密备份没有密码或助记词就解不开，等同于没有备份。

> **建议**：期末、换机前、批量导入前各导出一份，文件名带上日期（例如 `班主任-2026-11-02-backup.json`）。

### 2. 从备份恢复

恢复入口只在登录页，登录后无法在设置页覆盖当前库。

1. `登录页 → 从数据库登录`，选中 `.json` 备份包。
2. 程序识别为备份包后进入 `从备份恢复` 页，显示包内账号名。
3. 输入导出时的密码，或 `助记词（12字）`（两者其一即可；无密码账号的加密包可能两者都不需要）。
4. 点 `解包并恢复`。

结果与限制：

- 恢复成功会直接登录首页，或提示用原密码登录（取决于包类型）。
- 本机已存在同名账号时，先弹出「本机已存在账号…恢复将覆盖其现有数据，是否确认？」；确认后备份包内容替换原库。
- `超级隐私模式` 的账号不能在未登录状态离线恢复，程序会提示先在原机登录并关闭该等级。
- 备份包与登录账号身份不一致时会被拒绝。

### 3. 换机与重装的三种做法

| 做法 | 步骤 | 适用与限制 |
| --- | --- | --- |
| 备份包（推荐） | 旧机 `导出数据库` → 新机安装并打开 → 登录页 `从备份恢复` | 跨电脑可靠；需要导出密码或助记词 |
| 拷贝整个数据目录 | 完全退出程序 → 拷贝整个 `data` 目录到新机同位置 | 需要连同 `db-master.key` 一起拷贝，且更换 Windows 用户或电脑后主密钥可能无法解开 |
| 只拷贝库文件 | 拷贝 `<slug>.db` | 不可用：缺少主密钥，加密库打不开 |

关于第二种做法：主密钥由 Windows 的本地保护机制包裹，与当前 Windows 用户绑定。同一台电脑、同一个 Windows 用户下整目录拷贝通常可行；换电脑或换 Windows 用户时，加密库有很大概率打不开。因此常规换机以备份包为准。

> **易错**：只拷 `<slug>.db` 而不拷 `db-master.key`，加密库无法打开，且无法事后补救。

### 4. 加密与明文的转换

转换入口在 `设置 → 账号管理 → 安全等级`，规则见 [40 账号与安全等级](./40-security-levels.md) 第 3 节。与备份相关的两点：

- 明文库导出的备份包是明文，任何人拿到即可读取，适合内部留档，不适合外发。
- 超级隐私模式下不能直接切换落盘加密，程序会提示先关闭该等级。

### 5. 数据目录与搬迁

`设置 → 数据目录设置` 有三项，各自搬迁范围不同：

| 项目 | 改动的后果 |
| --- | --- |
| `数据库目录` | 存放 `index.db` 与各账号库、上传图片等用户数据；修改会整体搬迁现有数据并重启应用服务。搬迁前会预检 `index.db` 与 `db-master.key` 是否齐备 |
| `相册缩略图缓存` | 可再生缓存，可放到独立目录；切换后已有缩略图会按需重建 |
| `技能文件目录` | AI 技能 md 文件（按账号分文件夹）；修改会搬迁技能文件并重启服务；AI 长期记忆不在此目录，不受影响 |

> **易错**：手动移动 `数据库目录` 里的文件而不经过设置页时，程序仍按原路径查找；搬迁应通过设置页完成，或完全退出后整体移动并同步修改路径。

### 6. 升级、卸载与删除账号

- **升级**：安装包只替换程序文件，数据目录原样保留；升级不会要求重新登录或重新配置。
- **卸载**：只移除安装目录中的程序文件，数据目录保留。重装后原账号仍在。
- **删除账号**：`设置 → 危险操作 → 删除账号`，说明为「删除当前账号及其全部数据，操作不可恢复」。确认弹窗有 10 秒倒计时，倒计时结束前按钮不可点；确认后删除该账号的库文件与登记。
- 删除账号不清理多账号共享的上传图片与相册缩略图目录，这部分可能残留。

> **易错**：删除账号是彻底删除，撤销记录与备份都无法在应用内找回；删除前先导出一份备份。
