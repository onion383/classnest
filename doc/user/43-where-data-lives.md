# 43 · 数据在哪里

## 前言

- **适用对象**：关心数据存放位置、是否会被上传、什么操作会联网的用户
- **本篇解决的问题**：数据落在这台电脑的哪个目录；哪些操作会访问外网；局域网内其它设备能否看到
- **前提条件**：无；需要时可在 `设置 → 数据目录设置` 查看当前路径

---

## 具体方法

### 1. 数据只在这台电脑上

所有业务数据保存在本机，默认目录为 `%APPDATA%\classnest\data`（实际路径以 `设置 → 数据目录设置 → 数据目录` 显示为准）。这是唯一可改的数据目录；目录下按用途固定分成四层，各层随根目录一起搬迁，不需要、也不能单独设置位置。

| 层 | 常见内容 |
| --- | --- |
| `core/` | `index.db`（账号登记表）、`<slug>.db` 及各库的 `-wal` / `-shm`、`db-master.key`（本机主密钥）、`.jwt-secret`、`.sessions.json`、`.last-db` |
| `content/` | `uploads/`（班费收据、主题背景图）、`album-trash/`、`receipt-trash/`、`snapshots/`、`ai-memory/`（长期记忆，按账号一份）、`ai-skills/`（技能 md，按账号分文件夹） |
| `cache/` | `album-thumbs/`（相册缩略图，可再生）、`ffmpeg/`（视频组件缓存） |
| `logs/` | `backend.log`、`startup.log`、`inp.log` 等运行日志，排查问题时可提供给维护者 |

补充说明：

- 相册只保存索引，照片与视频仍留在用户原来放它们的文件夹里；移动或删除原文件后，相册中会出现缺失或预览失败。
- 截图与注释的保存位置不在数据目录，默认在系统「图片」文件夹下的 `screenshots`。见 [23 工具箱浮窗](./23-toolbox.md)。
- AI 的服务商密钥保存在本机账号库中，只在请求所选服务商时使用；它属于账号数据，会随 `导出数据库` 的备份包一起带走。

> **易错**：手动删除 `core/` 里的 `db-master.key`、`index.db` 或某个 `<slug>.db`，都可能让对应账号无法打开。需要清理时优先使用设置页里的功能。

### 2. 局域网与其它设备

- 程序内部由本机上的一个服务进程提供数据，只监听本机回环地址（`127.0.0.1`）。
- 因此不会触发 Windows 防火墙的「允许访问」弹窗，同一局域网内的其它电脑或手机也无法访问这台电脑上的班集数据。
- 换电脑时的数据传递只能通过备份包或手动拷贝目录，见 [42 备份与数据位置](./42-backup-and-data.md)。

### 3. 什么时候会联网

| 操作 | 联网对象 | 说明 |
| --- | --- | --- |
| 与 AI 对话 | 所选服务商（DeepSeek / OpenAI / Kimi / 通义千问 / 智谱清言 / 自定义地址） | 对话内容与本机数据片段直接发往服务商；本机程序没有中转服务器 |
| AI 联网搜索 | 仅 DeepSeek | 使用其它服务商时该选项不可用 |
| 检查更新、下载更新 | GitHub Releases | 只用于拉取安装包，不上传任何本机数据 |
| 打开外部链接 | 目标网站 | 例如协议、打赏、帮助等页面 |
| 相册、表格、统计、备份 | 不联网 | 均在本机完成 |

> **易错**：`明文模式` 下数据未加密，一旦通过备份包外发，或电脑被他人使用，内容可被直接读取；分享备份前留意这一点。

### 4. 可以自己管理的部分

- 更换数据目录：`设置 → 数据目录设置` 只有 `数据目录` 一项，修改会整体搬迁全部内容；说明见 [52 其他设置](./52-other-settings.md)。
- 打开数据目录查看内容：同一页的 `打开文件夹`。
- 全量备份：`设置 → 账号管理 → 导出数据库`。
- 删除账号及其数据：`设置 → 危险操作 → 删除账号`。

> **建议**：定期把备份包放在与电脑无关的位置（例如加密的移动硬盘），而不是只留在数据目录旁边。
