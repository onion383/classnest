# 50 · 主题与外观

- **适用对象**：希望界面更好看、或需要长时间看屏幕想调亮度的用户
- **本篇解决的问题**：三套主题的差别、日夜模式与跟随系统、图标与顶栏配色、背景图与透明度各管什么
- **前提条件**：无；背景图与透明度只对毛玻璃系主题生效

---

## 1. 两个入口

| 入口 | 位置 | 能做什么 |
| --- | --- | --- |
| 快速切换 | 标题栏的主题按钮（调色板图标）→ `切换主题` 弹窗 | 点卡片立即换主题，并可开关动画效果 |
| 完整设置 | `设置 → 主题设置` | 主题、图标样式、顶栏配色、日夜模式、跟随系统、提示合并、动画、背景图、透明度 |

两处改动都即时生效，没有「保存」按钮。

## 2. 三套预设主题

| 主题 | 样子 | 额外设置 |
| --- | --- | --- |
| `彩色色块主题` | 色块分明、对比强 | 无背景图与透明度设置 |
| `毛玻璃主题` | 半透明玻璃质感，默认主题 | 背景图片、透明度设置 |
| `新毛玻璃主题` | 玻璃质感更柔和 | 背景图片、透明度设置 |

三套都支持日夜配色，因此日夜模式开关都会出现。

> **建议**：投影或大屏演示时用 `彩色色块主题`，对比度高、远处也看得清；日常使用保留默认的 `毛玻璃主题`。

## 3. 日夜模式与跟随系统

- `日夜模式`：在 `日间` 与 `夜间` 之间切换，图标为太阳与月亮。
- `跟随系统`：开启后按操作系统的深色 / 浅色偏好自动切换。
- 手动切换日夜模式会自动关闭「跟随系统」，避免系统偏好覆盖手动选择。

`彩色色块主题`、`毛玻璃主题`、`新毛玻璃主题` 均提供夜间配色；界面上的日夜开关不出现时，说明当前主题没有夜间层。

## 4. 图标样式与顶栏配色

| 项目 | 可选值 | 影响范围 |
| --- | --- | --- |
| `图标样式` | `彩色图标` / `Emoji` | 侧边栏导航图标 |
| `顶栏配色` | `深蓝` / `白色调` | 标题栏与侧边栏的毛玻璃底色 |

默认值为 `彩色图标` 与 `白色调`。

## 5. 背景图片与透明度

这两组设置只在毛玻璃系主题下显示。

### 5.1 背景图片

1. 点 `选择本地图片`，选中 JPG / PNG / GIF / WebP 文件。
2. 选中后按钮旁显示文件名，下方出现预览缩略图。
3. 点 `清除` 可去掉自定义图，恢复主题自带的默认弥散光斑。
4. 留空（未选择图片）时使用默认背景。

### 5.2 透明度设置

| 滑块 | 范围 | 效果 |
| --- | --- | --- |
| `背景遮罩层（有自定义背景图时）` | 0%–100% | 数值越高背景图越不明显，越低越清晰 |
| `组件透明玻璃层` | 0%–100% | 控制卡片、表格、通知弹窗等玻璃层的透明度 |

> **易错**：背景遮罩层调到很低时，深色或花哨的图片会透到文字后面，阅读表格会吃力；数字与文字清晰优先于背景好看。

> **建议**：用 GIF 做背景时，动画会持续占用一点性能；性能面板提示卡顿时可先换回静态图或默认背景。

## 6. 提示合并与动画效果

- `提示合并`：相同类型的重复提示合并为一条并显示计数，避免连续操作时满屏提示。
- `动画效果`：关闭后禁用全部过渡与动画，包括窗口淡入淡出、弹窗与列表动效。低配置电脑或远程桌面下关闭可更流畅。

## 7. 主题设置存在哪

主题偏好保存在本机界面设置中，跟随这台电脑与这个 Windows 用户，不进入数据库，也不会随 `导出数据库` 的备份包带到新电脑。换机后需要在新电脑上重新选择主题。
