# 51 · 学期设置

## 前言

- **适用对象**：需要按学期统计座位指数、值日指数与课程表周次的用户
- **本篇解决的问题**：学期起止在哪里设置；它到底影响哪些页面；换学期后旧数据还在不在
- **前提条件**：无；未设置学期日期时大部分页面仍可正常使用，只是按学期结算的功能会提示缺少日期

---

## 具体方法

### 1. 使用范围

- 开学初，给本学期登记一个名称与起止日期。
- 学期中途发现周次算错（例如开学日期填晚了一周）。
- 需要回顾上一个学期，或为下个学期提前建好记录。

### 2. 操作路径

入口：`设置 → 学期设置`。

| 控件 | 作用 |
| --- | --- |
| `选择学期` | 在已有学期间切换当前学期 |
| `增加学期` | 输入学期名（例如 `2026秋季学期`）新建一条 |
| `修改学期名` | 改当前选中学期的名称 |
| `删除学期` | 删除当前选中学期，确认后不可恢复 |
| `学期开始时间` / `学期结束时间` | 日期选择器，改完点 `保存日期` 生效 |
| `本学期时长` | 只读，按起止日期折算为「共 N 周」 |

新增学期时只需填学期名，起止日期会按当前月份推算一个默认范围，随后可在上方调整。日期未改动时按钮旁显示「日期未改动」，`保存日期` 不可点。

首次安装不会自动创建默认学期；学期列表为空时，可在这里点 `增加学期`，或直接在课程表的「作息时间设置」里填写学期开始日期。

### 3. 结果长什么样

- 当前学期的起止日期会决定课程表的「第 N 周」计算。
- 座位与值日的快照补存范围以当前学期为上下界；座位指数结算也以学期范围为准。
- 页面底部提示「座位快照按天补存与座位指数结算均以当前学期范围为准」。

删除当前学期时，若还有其它学期，程序会自动把剩下最新的一条设为当前学期；一条不剩时按未设置处理。

### 4. 与课程表的关系

`设置 → 学期设置` 里的学期列表与课程表的「学期开始日期」使用的是同一份数据：

- 在课程表里改学期开始日期，`学期设置` 中的对应日期同步变化。
- 在 `学期设置` 里切换当前学期，课程表跟着切换到该学期的设置。

因此两处不需要重复登记，改一处即可。

### 5. 常见问题与限制

- **结束日期早于开始日期**：保存时被拦下并提示「结束日期不能早于开始日期」。这种组合会让快照补存整段失效，看起来像是历史记录一直是空的。
- **只填一端**：允许保存，表示另一端不限制；但 `本学期时长` 需要两端都有值才会显示。
- **未设学期开始日期**：座位指数结算会提示「未设置学期开始日期」，先补齐日期再结算。
- **旧数据不按学期分区**：旧版本或未建立学期期间录入的数据仍归属当前库，不会因为新增学期而被自动拆分到某一段。

> **易错**：删除学期不可恢复，且被删学期的日期设定无法找回；删除前先确认当前选中的是哪一条（选择框显示的名称）。

> **建议**：每学期开始时先建好学期并填准开始日期，后续的座位与值日统计才能按周对齐。
