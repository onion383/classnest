# 52 · 其他设置

## 前言

- **适用对象**：需要清理撤销记录、调整保存目录、排查卡顿或删除账号的用户
- **本篇解决的问题**：`撤销记录`、`性能`、`保存路径设置`、`数据目录设置`、`危险操作` 各分区做什么、有什么风险
- **前提条件**：无；重启类操作前先保存正在编辑的内容

---

## 具体方法

### 1. 撤销记录

入口：`设置 → 撤销记录`。

- 按数据来源分组，左侧组名（例如「学生表」「请假记录」），右上角显示「N 步可撤销」。
- 每条显示时间与操作说明；可撤销的记录带 `撤销` 按钮，已撤销的记录显示「已撤销」并带 `重做` 按钮。
- 顶部 `清空所有撤销记录` 会删除全部记录，清空后无法找回。
- 没有记录时显示「暂无编辑记录。在表格中修改数据后，这里会记录该次操作，之后可一键撤销、跨重启保留」。

记录跨重启保留，快捷键与范围限制见 [30 撤销与重做](./30-undo.md)。

### 2. 性能面板

入口：`设置 → 性能`。

#### 2.1 运行状态与重启

四个格子分别显示 `前端`、`后端`、`小组件`、`全局`：

| 状态 | 含义 |
| --- | --- |
| `正常` | 该进程存活 |
| `未运行` | 该进程未启动 |
| `部分未启动`（仅全局） | 前端、后端、小组件未全部存活 |

每格下方有对应的重启按钮：`重启前端`、`重启后端`、`重启小组件`、`全部重启`。

> **易错**：`重启前端` 会重新加载主窗口，页面内尚未保存的编辑会丢失；`重启后端` 会让正在进行的导入、导出、AI 对话中断。重启前先确认没有正在进行的操作。

#### 2.2 内存占用

上方汇总显示 `总计`、`平均`、`最高`、`前端`、`后端`、`其他`；下方按占用从高到低逐进程列出条形与数值。右侧 `回收` 会请求各进程释放可回收内存，耗时随进程数变化。

#### 2.3 上次启动耗时

底部 `上次启动耗时` 是上一次启动从进程开始到首屏内容真正绘制出来的时间，单位秒。数值持续偏高时可结合 [50 主题与外观](./50-theme.md) 的动画效果与背景图调优。

### 3. 保存路径设置

入口：`设置 → 保存路径设置`，两项独立设置：

| 项目 | 对应工具 |
| --- | --- |
| `注释截屏保存位置` | 工具箱里的注释工具 |
| `一键截屏保存位置` | 工具箱里的一键截屏 |

- 显示当前生效目录；未设置时显示默认目录 `Pictures\screenshots`（系统「图片」文件夹下的 `screenshots`）。
- `修改` 打开文件夹选择框；`打开文件夹` 在资源管理器中定位到该目录。
- 留空即使用默认位置。

选择目录时会做安全检查，以下情况会被拒绝：

- 盘符根目录（例如 `D:\`）；
- 系统保护目录（Windows 安装目录、`System32`、`WindowsApps` 等）；
- 指向文件的路径。

> **建议**：截图目录放在自己的文档或专门的教学资料文件夹中，便于期末归档；不必放在数据目录里。

### 4. 数据目录设置

入口：`设置 → 数据目录设置`，三项说明见 [42 备份与数据位置](./42-backup-and-data.md) 第 5 节：

- `数据库目录`：存放数据库与上传图片；修改会整体搬迁并重启应用服务，搬迁前会检查 `index.db` 与 `db-master.key`。
- `相册缩略图缓存`：可再生缓存，可放到独立磁盘；切换后缩略图按需重建。
- `技能文件目录`：AI 技能 md 文件；修改会搬迁并重启服务，AI 长期记忆不在此目录。

每项都有 `修改` 与 `打开文件夹`。

> **易错**：把数据库目录指向移动硬盘或网络盘后，硬盘未接入时程序无法打开数据库；更换目录后先确认新位置稳定可用。

### 5. 危险操作

入口：`设置 → 危险操作`。

- 唯一项目为 `删除账号`，说明为「删除当前账号及其全部数据，操作不可恢复」。
- 点击后弹出确认框，需等待 10 秒倒计时结束才能确认；倒计时期间按钮不可点。
- 确认后删除该账号的库文件与登记，账号从登录列表消失。
- 多账号共享的上传图片与相册缩略图目录不会被清理，可能残留。

> **易错**：删除账号不能通过撤销记录恢复，也不能在应用内反悔；删除前先 `设置 → 账号管理 → 导出数据库` 留一份备份。
