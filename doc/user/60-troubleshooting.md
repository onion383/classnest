# 60 · 故障排查

## 前言

- **适用对象**：遇到打不开、报错、数据看起来不对的用户
- **本篇解决的问题**：按现象快速定位原因，知道哪些能自助处理、哪些需要留日志求助
- **前提条件**：无；需要日志时先确认 `设置 → 数据目录设置` 中的目录路径

---

## 具体方法

本篇按「看到什么」组织。每条给出可能原因与可尝试的处理方式；跨篇的操作只给链接，不重复步骤。

### 1. 启动与登录

| 现象 | 可能原因 | 可尝试的处理 |
| --- | --- | --- |
| 打开后长时间白屏或一直转圈 | 本机服务尚未就绪、被杀毒软件拦截、数据目录不可读写 | 等待十几秒；`设置 → 性能` 查看 `后端` 是否「正常」；不正常时点 `重启后端`；仍无效则完全退出后重新打开 |
| 启动后窗口出现又消失 | 上一次安装或更新未完成、单实例锁残留 | 完全退出（含托盘）后重开；仍无效时重装安装包，数据不会丢失 |
| 登录页看不到原有账号 | 该账号库已损坏或主密钥变化，被登录列表过滤 | 改用 `从数据库登录` 选中对应 `.db`；仍不行时用备份包 `从备份恢复` |
| 输入密码提示错误 | 密码不符、库钥匙与当前主密钥不匹配、超级隐私账号状态异常 | 核对密码；忘记时走 [41 恢复密钥与找回](./41-recovery.md)；确认是否在别的 Windows 用户下打开过 |
| `从数据库登录` 提示本机未找到该数据库登记 | 选的是外来库或从别处拷来的 `.db` | 改用 `从备份恢复` 导入 `.json` 备份包，见 [42 备份与数据位置](./42-backup-and-data.md) |
| `从数据库登录` 提示该账号已开启超级隐私模式 | 超级隐私账号不能用库文件直接进入 | 回到登录页输入账号与密码，或用恢复词找回 |
| 登录后立刻回到登录页 | 会话失效、系统时间异常、切换了 Windows 用户 | 重新登录；确认系统时间正确；确认使用的是同一 Windows 用户 |

### 2. 数据看起来不对

| 现象 | 可能原因 | 可尝试的处理 |
| --- | --- | --- |
| 刚改的数据变回去了 | 编辑未保存（未按回车或未失焦）、撤销了上一步、切换了账号 | 重新编辑并确认保存；`设置 → 撤销记录` 查看是否被撤销，必要时点 `重做` |
| 误删了一行或一名学生 | 表格内删除、批量删除 | 先按 `Ctrl+Z`；再查 `设置 → 撤销记录` 逐条撤销；相册删除的图片可在相册回收站找回 |
| 座位或值日历史为空 | 学期日期缺失或结束日期早于开始日期 | 到 `设置 → 学期设置` 补齐日期；座位指数结算提示「未设置学期开始日期」时同理 |
| 相册里的照片看不到 | 原文件被移动、重命名或删除；相册只保存索引 | 把原文件放回原路径后重新扫描；删除前先看相册回收站 |
| 换机后账号打不开 | 只拷了 `<slug>.db`，缺 `db-master.key`；换了 Windows 用户 | 用旧机导出的备份包在登录页 `从备份恢复` |
| 备份恢复被拒绝 | 超级隐私账号未关闭保护、同名账号未确认覆盖 | 先在原机登录并关闭超级隐私；确认覆盖弹窗后再恢复 |

> **易错**：为了「清干净」而手动删除数据目录里的文件，很容易让加密库永久打不开。清理优先走设置页的对应功能。

### 3. AI 助手

| 现象 | 可能原因 | 可尝试的处理 |
| --- | --- | --- |
| `连接失败：…` | API Key 错误、Base URL 不对、模型名不存在、网络不可达 | 在 `设置 → AI` 重新做连通验证；核对三者的填写；更换网络后重试 |
| 长时间停在等待 | 请求超时（发现模型与连通验证各约 20 秒） | 减少一次发送的内容；检查代理；换用其它服务商配置 |
| 回复说不能联网 | 联网搜索仅 DeepSeek 支持 | 切换到 DeepSeek，或改为手动提供资料 |
| AI 说已修改但没有变化 | 权限为 `全部审批`，提案尚未确认 | 在提案浮窗点 `确认执行`；或先看右侧 `数据改动` 抽屉 |
| AI 改错了数据 | 已执行写入 | 用撤销记录回退，见 [30 撤销与重做](./30-undo.md)；重要操作前先导出备份 |

AI 的配置与权限说明见 [22 AI 助手](./22-ai.md)。

### 4. 相册扫描

| 现象 | 可能原因 | 可尝试的处理 |
| --- | --- | --- |
| 扫描很慢或一直不结束 | 首次全量扫描文件多；磁盘慢 | 在任务管理中查看进度；可暂停后分次继续；大目录分批加入 |
| 扫描中断 | 程序退出、目录被占用、文件被移动 | 重新进入相册页发起扫描；用增量扫描补齐 |
| 缩略图空白 | 缓存目录被清理或切换后尚未重建 | 等按需重建；仍空白时对相应相册重新扫描 |
| 视频没有画面 | 仅生成封面，未生成时显示占位 | 重新扫描；确认视频文件本身可播放 |

### 5. 导入与导出

| 现象 | 可能原因 | 可尝试的处理 |
| --- | --- | --- |
| 导入提示文件过大 | 超过 10MB 上限 | 拆分文件或删去无用列后再导入 |
| 导入后表头错位 | 表头前有标题行、合并单元格 | 整理成单行表头、去掉合并单元格；只保留第一个工作表 |
| 导入后行数变少 | 缺少受保护字段被过滤（学生需 `学号` `姓名`，班费需 `收支编码`） | 补齐字段后重新导入 |
| 导出内容比看到的少 | 选择了 `仅选中行` | 改为 `全部行`；或在筛选前重新勾选 |
| 导出的图片或 PDF 排版拥挤 | 列太多 | 导出前精简列，见 [32 导入导出](./32-import-export.md) |

### 6. 更新

| 现象 | 可能原因 | 可尝试的处理 |
| --- | --- | --- |
| 一直停在 `正在检查…` | 无法访问 GitHub | 检查网络、代理与 DNS 后重试 |
| `更新失败：网络连接失败…` | 同上 | 换网络后重试；不影响继续使用当前版本 |
| 下载进度长时间不动 | 网络波动、下载被中断 | 关闭弹窗后重新打开触发检查；必要时到发布页手动下载安装包 |
| `重启并安装` 无反应 | 安装包未下载完整 | 重新检查并等待 `新版本已下载` 后再点 |

### 7. 卡顿与显示

| 现象 | 可能原因 | 可尝试的处理 |
| --- | --- | --- |
| 页面切换卡顿 | 动画多、背景图为 GIF、内存占用高 | `设置 → 主题设置` 关闭 `动画效果`、换回静态背景；`设置 → 性能` 点 `回收` 或按需重启进程 |
| 表格滚动不流畅 | 行数很多、列很多 | 用筛选缩小范围；必要时导出后在 Excel 中查看 |
| 桌面小组件盖不住其它窗口 | 小组件固定置底 | 属设计行为：始终在其它窗口之下，可点击可拖动 |
| 工具箱浮窗不见了 | 开关关闭，或之前选了 `本次退出` | 到 `设置 → 工具箱设置` 重新启用，见 [23 工具箱浮窗](./23-toolbox.md) |
| 截图保存失败 | 目录被系统保护、指向文件、或盘符根目录 | 在 `设置 → 保存路径设置` 换成普通文件夹；错误提示会说明具体原因 |

### 8. 需要日志时

- 日志位置在数据目录中：`backend.log`（本机服务运行记录）、`startup.log`（启动耗时与阶段）。
- 反馈问题时附上：发生时间、当时做的操作、界面提示原文、这两个日志文件。
- 日志不包含业务数据正文，但可能包含账号名与文件路径；对外发送前可先确认内容。
