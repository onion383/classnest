# 62 · 附录

## 前言

- **适用对象**：需要快速查快捷键、导出格式或提示文案含义的用户
- **本篇解决的问题**：把全手册中零散但常用的对照表集中到一处，便于随手查
- **前提条件**：无

---

## 具体方法

### 1. 快捷键与鼠标规则

| 操作 | 作用 | 生效范围 |
| --- | --- | --- |
| `Ctrl + Z` | 撤销上一步 | 当前页面、当前表格；输入框内不触发 |
| `Ctrl + Shift + Z` | 重做 | 同上 |
| `Ctrl + Y` | 重做 | 同上 |
| `Enter` | 保存当前单元格的编辑 | 表格编辑状态 |
| 双击单元格 | 进入编辑 | 表格 |
| 单元格失焦 | 保存编辑 | 表格 |
| `Esc` | 取消 AI 助手的截图选区 | AI 对话页的截屏选区 |

撤销的完整规则（包括「为什么跨页面无效」「为什么每表只有 50 步」）见 [30 撤销与重做](./30-undo.md)。

### 2. 导出格式对照

| 格式 | 适合 | 说明 |
| --- | --- | --- |
| `HTML 表格 (.html)` | 发给别人直接看 | 带表格样式，浏览器可打开 |
| `Excel (.xlsx) - 带边框` | 继续加工、上报 | 带边框，最通用 |
| `CSV (.csv) - 无样式` | 导入其它系统 | 纯文本表格，无格式 |
| `Markdown 文档 (.md)` | 写文档、进知识库 | 表格语法 |
| `纯文本 (.txt)` | 快速查看、复制 | 以制表符分隔 |
| `JSON 数据 (.json)` | 备份、程序处理 | 保留字段结构 |
| `图片 (.png)` | 张贴、发群 | 整表截图 |
| `PDF 文档 (.pdf)` | 打印、留档 | 分页排版 |

`导出相册索引` 与 `导出分组` 不出图片格式；其余入口的格式支持见 [32 导入导出](./32-import-export.md)。

### 3. 常见提示文案

| 提示原文 | 出现场景 | 含义 |
| --- | --- | --- |
| `未设置学期开始日期` | 座位结算 | 座位指数按学期范围结算，需先到 `设置 → 学期设置` 填日期 |
| `结束日期不能早于开始日期` | 保存学期 | 日期顺序反了，保存被拦下 |
| `密码错误` | 登录、切换等级、关闭超级隐私 | 当前密码校验未通过 |
| `本机已存在账号「…」…是否确认？` | 从备份恢复 | 同名账号将被覆盖，需确认 |
| `本机没有可恢复的账号` | 本机信息恢复 | 本机没有可用的非隐私账号，改用恢复词或备份包 |
| `连接失败：…` | AI 连通验证 | 服务商地址、密钥或网络有问题 |
| `更新失败：…` | 检查更新 | 后接具体原因，见 [61 更新与版本](./61-update.md) |
| `已成功导出 …` | 导出面板 | 导出完成，文件已保存到所选位置 |

> **建议**：遇到不认识的红字提示时，先看这篇表格；表格里没有的，按 [60 故障排查](./60-troubleshooting.md) 的现象索引查找。

### 6. 隐私说明（一句话版）

数据保存在本机；加密库由本机主密钥自动解锁；联网只发生在 AI 对话、AI 联网搜索、检查与下载更新、打开外部链接这四类操作。

展开说明见 [43 数据在哪里](./43-where-data-lives.md)。

| 平台 | Windows 10 1709 及以上 |
