# 班集 · 用户使用文档

面向用户（老师）的操作手册。简介**如何使用、会得到什么、注意事项**；不解释源码结构、接口与算法。开发文档见 [../development/README.md](../development/README.md)。

- 适用版本：0.1.x
- 平台：Windows 10 1709 及以上
- 目标读者：老师

## 一、使用方法

按场景查阅即可，无需逐个阅读：

| 场景           | 从这里开始                                                                                                      |
| ------------ | ---------------------------------------------------------------------------------------------------------- |
| 第一次装、第一次用    | [01 安装与首次启动](./01-install-and-first-run.md)                                                                |
| 开学前想先有个整体规划  | [02 一学期的使用节奏](./02-semester-rhythm.md)                                                                     |
| 看不懂界面上的词     | [03 名词表](./03-glossary.md) → 再看对应页面篇                                                                       |
| 怕丢数据、想换电脑    | [40 账号与安全等级](./40-security-levels.md)、[41 恢复密钥与找回](./41-recovery.md)、[42 备份与数据位置](./42-backup-and-data.md) |
| 想让 AI 帮忙改数据  | [22 AI 助手](./22-ai.md)                                                                                     |
| 打不开、报错、找不到东西 | [60 故障排查](./60-troubleshooting.md)                                                                         |
